这份指南面向直接使用软件玩游戏的玩家。你不需要了解代码，按照页面名称和按钮操作即可。

**第一次使用，可以先看第 1～3 节；主要玩大乱斗，再看第 5 节；只想兑换魄罗商品，直接看第 11 节。**

文档根据当前项目功能整理，包含本次新增的符文装备自动切换、魄罗商店全量与分类选择、后台兑换通知。公开发布包可能尚未包含全部变化，请以安装版本和实际页面为准。

## 1. 第一次打开：先把客户端连上

### 1.1 准备软件

1. 从项目发布入口获取适合自己电脑的完整 Windows 发布包。
2. 将整个压缩包解压到固定文件夹，不要只从压缩包里拖出一个程序文件。
3. 运行 `sc助手.exe`。
4. 通过你平时使用的启动器打开 LOL，并完成登录和客户端更新。
5. 等待助手识别客户端，再查看首页的账号信息和顶部游戏状态。

助手需要使用当前电脑上已经登录的 LOL 客户端。没有登录时，查战绩、读取好友和执行客户端操作等功能可能不可用。账号登录仍在 LOL 或对应启动器里完成。

### 1.2 让助手帮你启动 LOL

入口：**设置 → 客户端与数据**。

1. 点击“选择安装文件夹”，选择 LOL 的安装目录。
2. 点击“立即启动 LOL”。
3. 如果启动器要求登录或更新，在启动器里完成。
4. 想以后打开助手时一起启动 LOL，可以勾选“启动助手时直接启动 LOL 客户端”。

安装路径也可以先留空，让助手尝试查找。没有找到时再手动选择。这里的“自动启动 LOL”和“开机自启助手”是两个独立选项。

### 1.3 第一局先这样用

1. 打开“设置 → 对局自动化”，选择“排位”或“大乱斗”预设。
2. 到“设置 → AI 与推荐”，确认“符文装备自动配置”和“选人伴随窗”的开关。
3. 进入选人后，先检查客户端里的符文、召唤师技能和推荐装备。
4. 进入游戏后，用局内信息面板查看双方近况。
5. 结束后到“战绩查询”查看详情。

**不配置 AI，也可以使用战绩、符文装备、选人辅助、奖励兑换等常规功能。**

## 3. 按习惯设置：预设与自动操作

入口：**设置 → 对局自动化**。这一页的大部分开关修改后会自动保存。

### 3.1 辅助预设怎么选

| 预设 | 适合谁 | 主要变化 |
| --- | --- | --- |
| 排位 | 想省去接受匹配、配符文等操作的峡谷玩家 | 开启自动接受、推荐与符文装备自动配置、选人伴随窗和局内信息面板 |
| 大乱斗 | 经常玩普通或海克斯大乱斗的玩家 | 在上述辅助基础上开启海克斯侧边栏；已设置备战席优先级时开启自动交换 |
| 纯净辅助 | 想减少自动操作和提醒，主要手动查询的玩家 | 关闭预设管理的自动辅助、自动发送和 AI 提醒等选项 |

预设会一次修改多项设置，并立即保存。三种预设都会关闭自动匹配、自动选禁、自动点赞、自动返回和自动 KDA 发送；需要时请再单独开启。

预设会保留你的个人方案、AI 密钥、换肤设置及按键绑定。“纯净辅助”也不等于卸载或恢复已经启用的换肤功能。

### 3.2 自动匹配、自动接受和接受延迟

- **自动匹配**：在适用的大厅状态尝试开始匹配。
- **自动接受**：出现匹配确认时，帮你点击接受。
- **接受延迟**：在填写的最小、最大毫秒数之间随机等待。两项都为 0 时立即接受。

例如填写 1000～3000，表示等待约 1～3 秒。延迟设得过长，可能赶不上客户端的接受倒计时。

### 3.3 自动禁用和自动选择英雄

1. 分别开启“自动禁用”或“自动选择”。
2. 在对应列表中设置英雄和优先顺序。
3. 进入选人后，助手会按优先级尝试可用的英雄。

两个相关选项：

- **仅预选，不锁定**：帮你预选英雄，最后的锁定由你自己完成。
- **补位时跳过**：客户端明确标记你为补位时，跳过自动选人。

英雄不可用、已被选走或当前阶段不允许操作时，客户端可能拒绝请求。可以查看日志了解结果。自动选禁和符文自动配置是不同开关，可以只开其中一项。

### 3.4 自动刷新和赛后操作

| 选项 | 作用 |
| --- | --- |
| 自动刷新对局 | 按设置的秒数更新对局页面信息 |
| 对局结束提醒 | 结束后通过消息或托盘提示 |
| 自动点赞 | 按所选策略给符合客户端条件的队友投票 |
| 点赞策略 | 可以选择随机队友、好友优先，或者保留手动投票 |
| 自动返回大厅 | 在赛后阶段尝试返回大厅 |
| 返回后继续匹配 | 返回后继续开下一把，需要同时开启自动返回大厅 |

保留手动投票时，助手会避免自动返回打断投票。能投几票、可投给谁，以客户端实际提供的选项为准。

### 3.5 手动大厅操作与暂停

“大厅与选人操作”可以快速创建大厅、取消当前匹配确认、退出英雄选择。队列 ID 可以理解为“游戏模式编号”；不熟悉编号时，使用“开黑大厅”里的模式列表更直观。

退出英雄选择仍按游戏本身的规则处理，并不会免除客户端可能产生的限制。

想临时停止自动辅助，可以在日志的诊断区域使用“本局暂停自动化”，需要时再点“恢复自动化”。后台商店兑换是单独提交的任务，不属于这个暂停开关。

## 4. 选人准备：符文、装备与个人方案

### 4.1 自动配置怎么开

入口：**设置 → AI 与推荐 → 选人辅助与符文 → 符文装备自动配置**。

当前新配置默认开启。旧版本已经保存为关闭的设置会继续保留，需要手动打开。

开启后：

1. 在客户端预选或选择英雄。
2. 等待助手识别英雄、游戏模式和分路。
3. 助手自动应用对应方案。
4. 更换英雄后，再配置新英雄的方案。

峡谷模式需要识别到分路；英雄、模式或分路信息尚不完整时，会先等待。普通大乱斗等无需分路的模式按英雄和模式匹配。

同一英雄、同一场景不会因连续刷新反复写入。你手动选择方案后，助手会保留当前选择；再次换英雄或分路时，会按新场景处理。

### 4.2 自动应用哪一套

选择顺序是：

1. 先找已启用“选人时自动使用”、且匹配英雄和场景的个人方案。
2. 多个个人方案同时匹配时，优先级数值高的先使用。
3. 没有匹配的个人方案时，使用推荐方案；曾手动选过的路线会被优先考虑。
4. 个人方案只有符文和技能、没有装备时，自动配置会补充该英雄的推荐出装。

推荐方案可能同时修改符文、装备物品集和召唤师技能。配置完成后请看一眼客户端，确认符合这一局的打法。

### 4.3 手动选符文和装备

常用入口：

- 选人伴随窗里的“一键选择符文装备”。
- “智能建议”里的“OP.GG 一键配置当前英雄”。
- 首页的“配置当前英雄”。

如果智能建议页里的 OP.GG 按钮没有显示，先在“设置 → AI 与推荐”开启“OP.GG 推荐”。伴随窗的手动入口可以独立打开。

操作步骤：

1. 打开方案窗口，确认英雄、模式和分路。
2. 查看符文、出门装、核心装备、可选装备和召唤师技能。
3. 选择喜欢的路线并应用。
4. 等待窗口返回成功或未完成的具体结果。

没有处在当前对局时，也可以浏览和预配置所示英雄。此时要先确认展示的是谁；召唤师技能需要在选人阶段应用。

### 4.4 装备配置成功后去哪里看

推荐出装写入的是 **LOL 客户端的自定义物品集**。进入游戏后，在商店的自定义物品集中查看对应出装。

这不是自动买装备。购买时机、临场换装和最终购买操作仍由你决定。

### 4.5 符文页满了怎么办

助手优先复用自己创建的符文页，避免每次换英雄都新增一页。

自动配置开启后，如果没有可复用的助手页、客户端又拒绝新建，会尝试替换当前可编辑的自定义页。临时页或不可编辑页不会被当成可覆盖页面。

如果当前页是你想长期保留的搭配，先把它保存为个人方案，或在自动配置前切换到允许替换的页面。手动方案窗口也会提供是否允许覆盖当前页的选项。

### 4.6 保存自己的符文方案

入口：**智能建议 → 我的符文方案**，也可以从英雄池的“配置个人方案”进入。

1. 在选人阶段，把符文和召唤师技能调好。
2. 点击“从当前选人捕获”。
3. 填写容易辨认的名称，例如“安妮中路·对线消耗”。
4. 检查英雄、模式和分路，设置优先级。
5. 想以后自动使用，勾选“选人时自动使用”。
6. 点击“保存修改”。

符文库还支持查看当前客户端符文页、立即应用、删除方案，以及“恢复应用前配置”。成功应用的推荐也会形成记录；是否参与个人方案自动选择，以该记录的自动使用设置为准。

高级用户可以填写“个人装备块”。输入框使用“分组名称:物品编号,物品编号”的格式，按行分组；普通玩家可以先留空，用自动补充的推荐出装。

“恢复应用前配置”针对最近一次记录的修改进行检查和恢复。如果账号、场次或相关配置又发生变化，可能需要手动核对；以恢复结果为准。

### 4.7 OP.GG 推荐和自动配置有什么区别

| 开关 | 主要作用 |
| --- | --- |
| OP.GG 推荐 | 后台准备推荐数据，并提供推荐入口；单独开启时不会自动弹出方案窗 |
| 符文装备自动配置 | 识别到匹配场景后，直接应用个人或推荐方案 |

只想自己选方案，可以关闭自动配置、保留 OP.GG 推荐。

## 5. 大乱斗：换英雄与增幅推荐

### 5.1 选人伴随窗

入口：**设置 → AI 与推荐 → 选人伴随窗**。

开启后，选人时会在客户端旁边显示小窗口，查看可见队友的段位、近期表现和自动选禁状态，并提供符文装备入口。窗口会跟随客户端移动、隐藏和恢复。

普通大乱斗和海克斯大乱斗的备战席英雄也会在这里显示。点击可用英雄，可以向客户端请求交换；交换是否成功，以客户端结果为准。

### 5.2 按优先级自动换英雄

入口：**设置 → 对局自动化 → 大乱斗备战席**。

1. 在“备战席优先级”里放入自己想玩的英雄，并排好顺序。
2. 开启“自动交换英雄”。
3. 备战席出现比当前英雄优先级更高的英雄时，助手会尝试交换。

这个功能使用现有备战席，不会替你随机重选英雄。

### 5.3 海克斯大乱斗增幅侧边栏

入口：**设置 → AI 与推荐 → 海克斯增幅助手**。

进入海克斯大乱斗后，可以查看当前英雄的专属增幅推荐，按白银、黄金、棱彩等类别切换。

当游戏里出现三张增幅卡片时：

1. 保持卡片完整显示。
2. 在侧边栏点击扫描，读取当前卡片名称。
3. 查看匹配到的增幅、样本和统计表现。
4. 如果识别有误，打开“确认增幅候选”或“增幅识别校正”，选择对应卡片并校正名称。
5. 回到游戏，由自己点击想选的增幅。

识别模型已经随软件提供，截图在本机内存中处理。扫描和校正只帮助你看清当前候选，不会替你选择游戏里的增幅。

“识别不确定”和“没有统计样本”不是一回事：前者是没认准名字，后者是名字已匹配但缺少统计。

侧边栏适用于窗口或无边框模式；独占全屏时会隐藏并停止扫描。

### 5.4 特殊模式的符文说明

海克斯大乱斗使用专属出装与增幅数据，不使用普通大乱斗推荐冒充专属数据。该模式没有常规符文页，应用方案时主要写入适用的装备和召唤师技能。

## 6. 局内信息：双方战绩与查看快捷键

### 6.1 对局页能看到什么

在“对局”页面，可以按蓝红双方查看当前可获取的玩家信息，包括：

- 玩家名称、当前英雄和等级等资料。
- 排位、赛季表现与近期战绩。
- 近期胜率、KDA 评估和相关样本说明。
- 有依据时显示的开黑标记。
- 当前对局可读取到的 KDA、补刀和视野等数据。

未公开身份、数据还在加载或接口没有返回时，会显示等待、未知或缺失，不代表该玩家没有打过。

### 6.2 换一种布局

对局页的布局选项提供：

| 布局 | 适合的查看方式 |
| --- | --- |
| 经典卡片 | 按玩家逐张查看，信息熟悉直观 |
| 双队总览 | 快速对照两队整体信息 |
| 位置对位 | 按位置查看对应玩家，实际对线仍需自己判断 |
| 详情工作台 | 集中查看较多细节 |
| 紧凑卡片 | 希望同屏容纳更多玩家信息 |

布局修改后会保存。玩家头像或名称支持身份复制、跳转战绩等操作，具体可看悬停提示；常见操作是单击复制、双击查询。

### 6.3 最近十场和 KDA 评估不是同一个统计范围

点击对局页“设置”，可在“最近十场·全部模式”和“当前模式·最近十场”之间切换。卡片里的近期胜率会跟着这个选项变化。

近期 KDA 评估则使用自己的统计规则，主要参考最近 50 场同模式有效对局。因此，卡片的十场胜率与 KDA 评估不一定来自相同的比赛。

### 6.4 在游戏里临时查看信息

入口：**设置 → AI 与推荐 → 局内对局信息面板**。

1. 开启局内对局信息面板。
2. 确认面板快捷键，默认是键盘左上角的反引号键，界面显示为“· 键”。
3. 在游戏位于前台时按住该键，显示信息面板。
4. 松开按键，或切出游戏后，面板收起。

建议在窗口或无边框模式使用。快捷键可改成自己顺手的按键或组合键，尽量避开游戏常用技能键。

## 7. 战绩查询、英雄池与个人复盘

### 7.1 查询自己或其他玩家

入口：**战绩查询**。

1. 点击“我的战绩”，查看当前登录账号。
2. 或输入完整游戏 ID，例如“玩家名称#标签”，再执行查询。
3. 也可以粘贴玩家的 PUUID，也就是用于准确定位账号的长编号。
4. 如果出现多个候选，确认名称、标签和大区后再选择。
5. 选择模式、翻页，或点击某场的详情。

常查的玩家可以收藏，下次从收藏列表选择。

跨区查询需要指定大区并使用目标玩家 PUUID。当前跨区查询主要支持战绩和数据统计；跨区排位、回放、本机英雄档案和个人复盘等功能存在限制，相关页面会提示。

### 7.2 对局记录与数据统计

“对局记录”用于逐场看输赢、英雄、时间和基础数据；“数据统计”用于查看所取得样本的汇总。查看详情可以进一步了解完整对局。

查询只覆盖客户端或数据服务实际能取得的历史，并不保证包含账号从创建以来的每一局。筛选后场次较少时，先看当前模式、采集时间和样本范围。

### 7.3 导出战绩

点击战绩查询中的导出按钮，选择保存位置。导出为可以用表格软件打开的 CSV 文件，包含可取得的模式、日期、英雄、结果、KDA、补刀、伤害、金币、视野和装备等信息。

导出有最多最近 5000 场的上限；达到上限时会提示，并不代表已经导出全部历史。必要的详情无法取得时，可能中止导出并说明原因。

### 7.4 英雄池档案

在“战绩查询”切换到“英雄池档案”，或从首页点击“英雄池”。

可以查看英雄的近期使用、胜率、KDA、补刀，以及可获取的拥有状态、熟练度等信息。支持搜索英雄、只看主练、只看已拥有等筛选。

选中想练的英雄，点击“切换主练标记”。以后可以只看这些英雄，也可以进入“配置个人方案”，为常玩英雄准备符文。

### 7.5 个人复盘中心

入口：**战绩查询 → 个人复盘中心**，或首页“上一局 / 成长”。

实用操作：

- **写笔记**：选中一场，记录一句下次想改进的事，再点“保存复盘标记”。清空笔记可取消标记。
- **只看标记**：快速找到自己想回看的对局。
- **查看详情 / 回放状态**：进一步检查该场数据，或查看回放能否下载。
- **比较近期趋势**：选单一模式，比较最近一组与此前一组的个人数据，避免把不同玩法混在一起。

### 7.6 一分钟复盘和练习目标

“一分钟复盘”会展示值得保持、值得关注和下一局一个目标。它主要与此前有限的同英雄、同模式记录比较，不会仅靠最终战绩推断每次死亡或输赢原因。

设置练习目标时：

1. 点击“练习目标”。
2. 选择模式，必要时限定英雄。
3. 选择想关注的指标、目标值和局数。
4. 点击“保存并开始新一轮”。

例如练习补刀、控制死亡或提高视野。死亡目标按“不超过”判断，其余适用指标按“至少”判断。目标只统计保存后开始、且在当前取得样本中的有效对局，缺失指标不会直接计为失败。

### 7.7 主练英雄和个人方案的版本提醒

先标记主练英雄，再点击“主练与方案版本提醒”。助手会对照关注的英雄及个人方案中的装备、符文资源，列出可检测到的变化。

查看后点击“已查看，保存比较基准”，下次以这一版为参照。这是资源变化提醒，不等于完整的官方更新公告，也不会自动替你改写符文方案。

## 8. KDA 评估：怎么看、怎么发送

### 8.1 评估代表什么

近期评估主要根据最近 50 场同模式有效对局的累计 KDA：先加总击杀、助攻和死亡，再计算比例，不是简单平均每一场的 KDA。

默认需要至少 10 场有效样本才按设置进行评级，样本下限可在“设置 → AI 与推荐”调整。同模式没有有效 KDA 样本时，可能改用全部模式作为参考，并注明范围。

“上等马”“中等马”等文字是软件的近期表现标签，不是段位、官方评价或本局胜负预测。样本不足会显示“数据不足”；胜率与 KDA 缺失的数据也会分别处理。

### 8.2 自动发送

入口：**设置 → AI 与推荐 → 战绩评估与 KDA 发送**。

| 开关 | 发送到哪里 | 内容范围 |
| --- | --- | --- |
| 选人 KDA 发送 | 当前客户端选人聊天 | 可获取到的我方近期评估，加载完成后发送一次 |
| 对局 KDA 发送 | 游戏内聊天 | 双方近期评估，等待游戏就绪且位于前台后发送一次 |
| 单人一行 | 游戏内聊天的排版选项 | 每位玩家单独一条；关闭时按蓝红双方汇总 |

选人文案可以使用界面说明里的占位文字，例如 `{allies}` 或 `{players}`。选人发送范围仍以可公开取得的我方信息为准，不会因为写了一个敌方占位符就取得隐藏身份。

### 8.3 手动快捷发送

入口：**设置 → 喊话**。

- 默认 **F9**：手动发送当前对局 KDA 汇总。
- 开启逐人 KDA 后，**小键盘 1～5** 对应蓝方五人，**6～9、0** 对应红方五人。
- 小键盘顺序按卡片从左到右、从上到下；需要开启 Num Lock。
- 在“自定义测评文案”中可以修改对应文字。

手动热键与自动发送开关独立。即使关掉自动发送，手动热键仍可能有效；如果不需要，也要在喊话设置里关闭。发送到队友还是所有人，遵循游戏内喊话的相关选项和客户端聊天权限。

## 9. 快捷喊话与自定义词库

入口：**设置 → 喊话**。

### 9.1 发送一句话

1. 从默认词库或自定义词库选择短句。
2. 查看待发送内容预览。
3. 点击“发送到客户端群聊”或“一键发送到游戏”。

“客户端群聊”用于可用的客户端聊天场景；“发送到游戏”需要游戏聊天可以接收输入。

### 9.2 添加自己的短句

在“自定义词库”里一行填写一句，保存后即可选择或随机发送。可以写常用沟通，例如“我先回城，等我一下”或“下一条龙提前集合”。

自定义词句每句最多 500 字。多选一次最多发送 10 句，发送顺序按词库顺序排列。

### 9.3 发送方式

| 选项 | 含义 |
| --- | --- |
| 多选 | 一次选择多句话，按顺序发送 |
| 逐字发送 | 按字符逐个输入 |
| 游戏内发给所有人 | 使用游戏的所有人聊天方式；能否发送仍受游戏设置限制 |
| 游戏内使用粘贴输入 | 通过剪贴板粘贴内容 |
| 发送间隔 | 限制连续发送频率 |
| 测试游戏回车 | 检查是否能正确向游戏聊天发送回车 |

游戏内热键通常只在 LOL 位于前台时生效。上一组消息还在发送时，需要先等待。

### 9.4 默认喊话热键

| 按键 | 作用 |
| --- | --- |
| F6 | 默认词库随机一句 |
| F7 | 自定义词库随机一句 |
| F8 | 发送当前多选短句 |
| F9 | 发送当前对局 KDA 汇总 |

点击快捷键输入框，再按下想设置的按键或组合键。避免重复绑定，并确认对应功能开关已开启。自定义词库和文案填写后，按页面的保存提示操作。

## 10. AI 建议：按需配置和使用

这是可选功能。普通战绩查询、符文推荐、增幅统计和魄罗商店不要求填写 AI 密钥。

### 10.1 配置连接

入口：**设置 → AI 与推荐 → AI 服务连接**。

1. 选择你使用的服务商，或兼容服务类型。
2. 按服务商提供的信息填写接口地址和 API Key。
3. 点击“获取可用模型”，选择可用模型，或填入服务提供方给出的准确名称。
4. 点击“测试连接”，检查结果。
5. 使用页面的保存按钮保存连接配置。
6. 开启“AI 时间线建议”。

API Key 是调用 AI 服务的密钥，不是 LOL 密码。服务能否使用、费用如何计算，由你选择的服务提供方决定；助手不包含其调用额度。

AI 连接字段需要主动保存，和自动保存的普通开关不同。已保存密钥时，输入框留空表示保留原密钥；想删除要使用清除并保存的操作。

### 10.2 查看建议

打开“智能建议”，可以：

- 查看当前重点建议，以及展开后续建议。
- 点击“重新分析”，在允许的间隔内更新。
- 点击“本次使用的数据”，了解建议参考了哪些信息。
- 点击“本局建议记录”，回看本局已生成的内容。
- 使用页面提供的反馈操作记录执行感受。
- 需要明确对线分析时，手动“确认对线对象”。

没有足够数据、没有可靠的新行动或尚未配置服务时，页面会显示相应状态。建议只是决策参考，最终怎么打由你判断。

### 10.3 自动刷新、请求预算和浮窗

开启动态建议后，助手按游戏状态和设置的节奏请求分析。“兜底分析秒数”可以理解为没有新触发时的补充分析周期。

“最短间隔”防止请求过密，“本局请求上限”限制一局中的请求次数。选人和局内共享预算，失败请求也会占用次数。手动重新分析同样有最短间隔。

想在游戏里看到建议，可开启“游戏内显示建议浮窗”，再调整位置、横向纵向偏移和停留时长。关闭浮窗后，仍可到智能建议页面查看。

### 10.4 发送哪些数据

启用并配置云端分析后，可能发送英雄、模式、阶段、阵容、时间、金币、本人状态、可见战绩和装备、公开事件、已确认的对线或增幅候选，以及最近建议和反馈。

这条 AI 分析流程不发送玩家名称、账号标识、聊天、截图或客户端认证信息。完整本局建议记录保留在本次运行的内存中。休息室属于另一项主动分享功能，公开范围见第 12 节。

## 11. 奖励领取与魄罗商店兑换

入口：**设置 → 客户端工具 → 回放与备份 → 待领取奖励**。

### 11.1 扫描和领取奖励

1. 点击“扫描与领取客户端奖励”。
2. 等待扫描商城每日箱、战令和待选奖励等来源。
3. 查看每项是可领取、需要选择、已领取，还是暂时不可用。
4. 无需选择的项目，可以使用“领取全部无需选择的奖励”。
5. 需要选择的奖励，先勾选符合要求的项目，再点击“领取所选奖励”。

不同奖励可能要求选择不同数量。扫描出来并不一定都能领取，要看当前账号是否满足领取条件。页面可以展开各级奖励或礼包的状态明细。

### 11.2 打开魄罗商店

点击“魄罗商店多选兑换”，或者在奖励窗口里打开“魄罗商店”。

进入后先读取：

- 当前账号的魄罗赏银、魄罗赏金余额。
- 商品名称、每份价格和使用的货币。
- 剩余兑换次数。
- 当前是否可兑换。

“已达兑换上限”“未开放”“余额不足”等项目不会被当作正常可兑换商品勾选。这个窗口展示确定物品兑换，不包含随机抽取操作。

### 11.3 按类型批量勾选

页面会按商品内容提供“全选皮肤碎片”“全选英雄碎片”“全选图标”等选项。存在对应商品时，还会显示表情、守卫皮肤、炫彩、其他等类别。

1. 勾选一个类型，会选中这一类里所有当前可兑换商品。
2. 可以同时勾选多个类型。
3. 取消某个类型，只清除该类型的选择。
4. 不想兑换某个具体商品，可以再单独取消。

“全选可兑换”用于选择所有可兑换类型，“清空勾选”用于全部取消。

### 11.4 “兑换全部数量”是什么意思

这个选项**默认勾选**。它不是自动选择所有商品，而是决定“已经选中的商品要兑换几份”。

开启后，助手按商品展示顺序，在剩余限购次数和当前余额允许的范围内计算数量。赏银和赏金分别计算；前面的商品用掉一部分余额后，后面的商品按余下余额计算。

例如：你有 75 赏银，勾选的第一种碎片每份 10、还可换 3 份，第二种每份 20、还可换 5 份，那么会先给第一种安排 3 份，再给第二种安排 2 份，预计花费 70 赏银。

如果后面的某个商品已经分不到足够余额，会显示本次跳过。想把余额留给它，可以取消前面的商品，或关闭全量选项改为手动数量。

取消“兑换全部数量”后，各行数量框可以自己填写。页面会实时计算份数、总赏银和总赏金；超过余额时不能提交。

### 11.5 后台兑换怎么用

1. 核对勾选商品、数量和总价。
2. 点击“兑换所选物品”。
3. 看到“已提交后台兑换”后，可以关闭商店窗口，也可以切换到助手其他页面。
4. 保持整个助手运行，并保持 LOL 客户端正常登录和网络连接。
5. 任务完成后，查看主窗口提示、托盘通知或消息记录。
6. 重新打开商店，可以查看当前任务状态，或本次运行中最近一次任务的结果；结果只在对应账号下展示。

**关闭商店窗口不会取消已提交任务；退出整个助手不会继续在后台兑换。** 同一时间只允许一个商店兑换任务，重新打开窗口不会自动再提交一次。

兑换会分批执行，每一份都要核对结果。超过 100 份时，会继续按批处理；某批失败或结果未确认时，停止后续部分，不会自动重试可能已经提交的兑换。

### 11.6 怎么看结果

| 结果 | 意思 |
| --- | --- |
| 兑换成功 | 本次请求的份数已确认完成 |
| 已确认兑换一部分 | 部分份数已成功，其余未全部完成 |
| 被拒绝 | 当前账号、价格、余额、限购或其他条件不再允许兑换 |
| 结果未确认 | 请求可能已经提交，但暂时无法确认最终结果 |
| 未提交 / 已跳过 | 任务停止后，这部分没有继续提交 |

结果未确认时，先到 LOL 客户端核对到账、余额和限购，再刷新商店。不要把“未确认”直接当作“完全没兑换”。

## 12. 好友、休息室与开黑组队

### 12.1 查看好友

入口：**设置 → 客户端工具 → 好友活动**。

可以刷新好友列表和活动，查看在线状态、队列和游戏时长等可用信息。双击好友可以查询其战绩。对有可观战对局的好友，可以手动点击观战；能否启动以客户端提供的状态为准。

### 12.2 使用 lol 休息室

打开主页面“lol休息室”，确认服务器地址后点击“保存并连接”。需要使用与其他玩家相同的休息室服务器，才能在同一频道互动。

连接后可以浏览公共消息、发送文字、选择表情包和 @成员。未登录 LOL 时可以查看消息，登录后才能按当前身份发言。Enter 发送，Shift+Enter 换行，每条最多 500 字。

这里是公共频道，昵称和大区会公开展示。“公开游戏状态与战绩”是额外分享选项，关闭它不等于匿名聊天。

### 12.3 发布和加入招募

**想找人来一起玩：**

1. 点击“开黑招募”。
2. 按界面填写模式、人数、位置或补充说明。
3. 确认后“发布到公频”。
4. 到“招募列表”查看报名和管理状态。
5. 不再找人时，结束招募。

**想加入别人的队伍：**

1. 打开“招募列表”，按同大区、可加入等条件筛选。
2. 查看详情，点击“报名加入”。
3. 复制发起人的完整游戏 ID，在 LOL 客户端添加好友并确认组队。
4. 不参加时退出报名，释放名额。

报名是占用招募名额，不会自动把陌生人拉进游戏大厅。段位、位置和队伍要求需要双方确认。

### 12.4 常用队友与通知

成员菜单中可以复制游戏 ID、收藏常用队友、关注上线提醒或屏蔽玩家。“更多”里可以管理组队偏好与常用队友，方便下次再组队。

通知设置支持免打扰、游戏中静音，以及五杀、超神、晋级等播报选项。只想少看消息，可以调整这些选项，不必每次断开频道。

### 12.5 开黑大厅

入口：**设置 → 客户端工具 → 开黑大厅**，也可以从招募和常用队友入口打开。

操作顺序：选择当前可用模式 → 创建大厅 → 邀请已有的在线好友 → 设置首选和次选位置 → 确认队伍 → 开始匹配。

也可以刷新并接受客户端已有邀请。邀请对象必须符合客户端条件，选择到一个名字不等于已经邀请成功，要看操作结果。

## 13. 回放、备份和客户端资料

### 13.1 下载和观看回放

入口：**设置 → 客户端工具 → 回放与备份 → 对局回放**。

填写对局 ID 后，可以下载回放或观看回放。也可以在战绩、复盘相关页面对选中的一局查看回放状态。

对局 ID 是一场比赛的编号，和玩家 ID 不同。旧版本、跨区或客户端没有回放资源的对局可能无法观看，以状态提示为准。

### 13.2 备份和恢复游戏设置

仍在“回放与备份”分类下：

1. 输入一个备份名称，例如“常用键位”。
2. 点击“保存当前游戏设置”。
3. 恢复时，在列表中选中备份，点击“恢复选中备份”。
4. 查看当前值和备份值的预览。
5. 按需勾选“游戏设置”“按键设置”，执行恢复并查看核验结果。

不再需要的备份可以从列表删除。这里保存的是相应游戏配置，不是整个游戏安装文件，也不是账号资产备份。

### 13.3 在线状态、签名、生涯背景和头像

入口：**设置 → 客户端工具 → 资料与外观**。

- 选择在线、离开、请勿打扰等状态，填写文案后更新在线状态。
- 使用“清除挑战角标”调整客户端资料展示。
- 在生涯背景或召唤师头像里“浏览选择”，先预览，再点击应用。
- 熟悉对应编号时，也可以按皮肤 ID 或头像 ID 操作。

是否能应用某项资料，由当前客户端和账号权限决定。预览到图片不代表已经拥有该内容，也不代表一定允许应用。

### 13.4 英雄 T 级和大乱斗平衡

入口：**设置 → 客户端工具 → 英雄数据**。

选择模式后读取英雄 T 级，或读取极地大乱斗的平衡修正。适合选英雄前快速了解统计与模式差异。数据是外部统计参考，不是对你个人熟练度的评价。

“增幅识别校正”也在这个分类下，可以查看三张卡片并修改本地识别名称。

## 14. 外观、窗口、托盘与快捷键

入口：**设置 → 外观与窗口**。

- **主题**：浅色、深色、跟随系统。
- **语言**：简体中文、繁体中文、英文。
- **透明度**：40%～100%，数值越小，助手窗口越透明。
- **按住置顶键**：临时把助手显示在前面，松开后收起到托盘。
- **快捷键范围**：可以限定只在 LOL 位于前台时响应。
- **最小化到托盘**：窗口隐藏后，从系统托盘恢复。
- **游戏分辨率**：按实际游戏分辨率设置，避免相关显示或操作与画面不符。

游戏里的“对局信息面板快捷键”和客户端、桌面上的“助手按住置顶键”是两个设置，虽然默认使用相同键位，作用不同。

### 默认快捷键速查

| 按键 | 作用 | 去哪里修改 |
| --- | --- | --- |
| 左上角反引号键，通常与 `~` 同键 | 按住查看局内信息；其他适用场景临时显示助手 | AI 与推荐 / 外观与窗口 |
| F6 | 随机发送默认短句 | 喊话 |
| F7 | 随机发送自定义短句 | 喊话 |
| F8 | 发送多选短句 | 喊话 |
| F9 | 手动发送对局 KDA | 喊话 |
| 小键盘 1～5 | 蓝方逐人 KDA | 喊话，需要开启对应开关 |
| 小键盘 6～9、0 | 红方逐人 KDA | 喊话，需要开启对应开关和 Num Lock |
| Home | 打开换肤浮窗 | 游戏换肤，需要启用核心与快捷键 |
| Ctrl+Alt+← / Ctrl+Alt+→ | 上一款 / 下一款英雄皮肤 | 游戏换肤，需要启用核心与快捷键 |

这些是默认绑定，不代表所有功能都已开启。点击快捷键输入框后按键录入；遇到冲突先检查是否被其他功能或软件占用。

## 15. 游戏换肤与其他实验性功能

入口：主页面 **游戏换肤**。这是独立模块，默认关闭。

**页面已提示：第三方换肤存在账号处罚风险，游戏更新后可能需要重新适配。** 它不等于账号拥有对应皮肤，也不能通过它改变真实段位。

### 15.1 英雄换肤

1. 先查看当前模式和兼容性提示。
2. 开启“启用独立核心”，进入可读取的对局。
3. 点击“读取当前英雄”。
4. 搜索并选择可用的皮肤与形态，查看应用结果。
5. 可以使用已启用的 Home 浮窗或上一款、下一款热键。

助手可以记住英雄上次的选择，适用时自动应用。状态不确认时，先重新读取并检查画面，不要把未确认当作完全没有执行。

### 15.2 小兵和眼位

切换到“小兵与眼位换肤”：读取当前对象 → 选择小兵主题和自己的眼位皮肤 → 应用对象皮肤。

应用后会继续同步本局新生成的相关对象。需要还原时，使用“恢复对象原皮”。

### 15.3 视距

“其他设置”里提供视距相关开关和恢复按钮。当前可调范围、滚轮行为及记忆状态以页面提示为准。

可以重新读取视距；按滚轮中键或使用“关闭并恢复默认”恢复游戏原本视距。Home 面板也提供对应开关。

### 15.4 停用和恢复不是同一件事

| 操作 | 含义 |
| --- | --- |
| 关闭启用开关 | 停止新的请求，不保证已经生效的外观自动恢复 |
| 恢复基础皮肤 | 切回该英雄基础皮肤 |
| 恢复对象原皮 | 还原本局相关对象外观 |
| 恢复原皮并停用 | 尝试恢复本局记录的原状态，再停用功能 |

如果提示恢复未核验，请检查游戏画面，必要时退出对局结束相关驻留状态。

### 15.5 哪些选项暂时不能用

- **混合模式**：实验方式，需要配套驱动等条件。普通玩家不需要为了常规战绩和符文功能配置它；可在退出对局且关闭功能后切换模式。
- **段位边框**：以读取到的兼容状态为准。当前随附核心页面标注待适配时，不能当作已经可用的功能。
- **技能冷却计时**：设置页中的召唤师技能、我方和敌方技能计时属于功能预览，当前暂不能开启。

## 16. 设置保存、缓存、日志与更新

### 16.1 哪些设置需要点保存

| 内容 | 保存方式 |
| --- | --- |
| 对局自动化开关、主题、语言、透明度等常用设置 | 修改后自动保存 |
| LOL 安装路径 | 编辑后离开输入框保存 |
| AI 服务商、接口地址、模型、密钥 | 按页面按钮保存连接配置 |
| 自定义词库、KDA 文案、换肤快捷键、个人符文方案 | 按对应页面的保存按钮或保存提示操作 |
| 备份、招募发布、商店兑换、资料应用 | 需要点击对应执行按钮，不会只因打开页面就提交 |

保存结果以页面提示为准。切换预设会重新调整它管理的多项开关，之后可以继续修改。

### 16.2 清理缓存

入口：**设置 → 客户端工具 → 本地缓存**。

可以查看和分别清理游戏图标与名称、符文装备推荐、对局战绩与玩家资料、强化图标等缓存。

清理后，后续查看会重新获取数据，第一次加载可能慢一些。设置、密钥、收藏、个人符文和游戏设置备份会保留。内存大小显示的是估算的数据量，不等同于整个程序的内存占用。

### 16.3 日志和诊断

功能没反应时，先看当前页面的结果，再到“日志”查看连接、游戏阶段和对应功能记录。

诊断区可以刷新接口能力、查看功能不可用的原因、暂停或恢复自动化，以及重试赛后失败步骤。日志路径可以通过页面提示查看。

反馈问题时，带上软件版本、发生在哪个页面、当时处于大厅/选人/游戏/赛后哪个阶段，以及完整错误提示。不要发送自己的 AI 密钥或客户端认证信息。

### 16.4 更新软件

在“关于”中查看版本并检查更新。发现新版本后，可以按页面选择下载来源；支持的更新流程会先下载、校验，再由你选择是否重启安装。

下载更新时可以继续使用当前软件。准备重启安装前，先确认没有仍在进行的商店兑换等后台任务。

## 17. 常见问题与处理方法

### 打开后首页没有账号，怎么处理？

先确认 LOL 已启动并完成登录，不是只打开了启动器。再等一会儿查看连接状态。如果一直未连接，到“客户端与数据”检查安装目录，再看日志里的连接提示。

### 第一次加载图标、战绩很慢，正常吗？

首次需要读取或下载资源，部分数据还要逐项加载。先等待当前任务完成。反复切页或频繁刷新不一定更快；如果明确提示失败，再按提示重试。

### 为什么选了英雄没有自动配符文？

依次检查：

1. “符文装备自动配置”是否开启，是否因切换预设而改变。
2. 当前是否仍在选人阶段，自动化是否被暂停。
3. 英雄、模式和峡谷分路是否已识别。
4. 页面或日志是否提示推荐加载失败、符文页不可写等原因。

可以先通过“一键选择符文装备”手动确认英雄和方案。进入游戏后，不能继续按选人阶段的方式修改符文。

### 显示装备配置成功，为什么没有替我买装备？

成功表示物品集已经写入。进游戏后到商店的自定义物品集中查看和购买。

### 我已经关掉自动 KDA，为什么按 F9 仍然发送？

自动发送和手动快捷键独立。到“设置 → 喊话”关闭手动 KDA 热键；小键盘逐人发送也有单独开关。

### 为什么十场胜率与 KDA 标签看起来对不上？

十场列表受对局页的筛选设置影响，KDA 标签主要使用最近 50 场同模式有效样本。先看各自的统计范围和样本数。

### 局内面板或海克斯侧边栏没有出现？

检查对应开关、是否进入适用模式、游戏是否位于前台，以及是否使用窗口或无边框模式。局内信息面板需要按住配置的查看键；海克斯侧边栏也不会在普通模式下按海克斯功能显示。

### 增幅认错了，或没有胜率？

先确认三张卡片完整显示，再重新扫描。认错名字可到识别校正窗口手动修改；名字正确但没有样本时，应理解为统计不足，不是识别失败。

### 为什么 AI 没有给建议？

检查连接配置是否保存、测试是否成功、模型是否可用、AI 总开关是否开启，以及本局预算或间隔是否已达到限制。没有可靠新行动时，页面也可能选择继续观察。可以查看“本次使用的数据”和状态说明。

### 商店“兑换所选物品”按钮为什么不能点？

检查是否选中了可兑换且数量大于 0 的商品；手动数量是否超出余额；是否已有后台任务；以及兑换后是否还在等待刷新余额。没有足够余额或剩余限购为 0 的商品不能正常提交。

### 勾选了“兑换全部数量”，为什么某些商品数量是 0？

全量模式会按所选商品的展示顺序分配余额，前面的商品可能已经占用余额。可以减少前面商品、换一组选项，或取消全量后手动分配。

### 关闭商店后，怎样知道兑换完成？

保持助手运行，等待主窗口或托盘通知；也可以重新打开商店看状态。如果系统没有展示托盘气泡，仍可查看助手消息记录和商店结果。

### 兑换只成功一部分，要再点一次吗？

先核对每项结果和客户端到账情况，再刷新余额。对“结果未确认”的请求不要直接重复提交；确认实际未完成且仍可兑换后，再按最新页面重新选择。

### 休息室报名了，为什么还没进队伍？

报名只占招募名额。需要复制发起人完整游戏 ID，在 LOL 客户端建立好友或邀请关系，再通过开黑大厅完成组队。

### 关闭换肤开关，为什么没有恢复原皮？

关开关主要停止新请求。需要还原时使用“恢复原皮并停用”，再看核验结果。恢复基础皮肤和恢复本局原皮也不是同一个操作。

### 恢复备份、观战、回放或修改头像被拒绝？

这些操作受账号、当前游戏阶段、资源权限和客户端版本影响。查看返回原因；不确定功能是否适配时，在诊断区刷新能力并查看可用原因。

### 程序像是消失了，但没有退出？

看看系统托盘，点击助手图标恢复。如果配置了按住置顶键，松开后也可能按设定收起到托盘。

## 18. 常用名词说明

| 名词 | 通俗解释 |
| --- | --- |
| Riot ID / 完整游戏 ID | 通常是“名称#标签”，用于识别玩家 |
| PUUID | 一串较长的玩家账号编号，方便准确查询，跨区查询时也会用到 |
| 对局 ID | 某一场比赛的编号，回放和对局详情会用到 |
| 队列 ID | 游戏模式或匹配队列的编号；不熟悉时用模式列表选择即可 |
| KDA | 击杀、死亡、助攻相关的表现比例，具体统计看页面的样本说明 |
| OP.GG 方案 | 来自公开统计的符文、出装等推荐，不保证适合每一局 |
| 个人方案 | 自己保存的英雄、模式和分路搭配，可以包含符文、技能和装备 |
| 自定义物品集 | 商店里按分组展示的一套出装清单 |
| OCR | 从画面中识别文字，这里主要用于读取增幅名称 |
| API Key | 调用 AI 服务的密钥，不是游戏密码 |
| 缓存 | 为了下次加载更快，在本机保留的可重新获取的数据 |
| 核验 / 已确认 | 操作后又读取状态进行检查；与单纯发出请求不同 |
| 待适配 / 功能预览 | 页面有入口或说明，但当前版本未必能执行 |

需要向朋友介绍软件时，可以直接分享 [功能介绍](../README.md)。
