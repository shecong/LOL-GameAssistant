# 换肤恢复与停用

日期：2026-10-10。

新增按钮“恢复并停用”。它恢复当前英雄的基础皮肤（编号 0，不是进入对局时选择的付费皮肤），回读基础编号、加密编号、实际皮肤层编号及模型，随后关闭功能并保存开关状态，清空当前列表、停止轮询与快捷键请求。

停用开始时使排队选择失效；已有原生动作无法保证撤回，等待串行队列结束后才执行恢复。新增请求会被拒绝。恢复失败、对局退出、超时或结果不明时同样关闭功能，不自动重试，也不显示恢复成功。

原生命令行主机现在先调用 UnhookWindowsHookEx，再输出响应；响应增加 transport_hook_released，服务只有在解除钩子核验为 true 时允许状态核验通过。该结果表示当前请求的消息钩子解除，不证明没有其他工具的钩子，也不证明游戏内 DLL 已从地址空间消失。

核心响应增加 module_pinned。拉克丝与娑娜特殊模型路径成功调用 PIN 后，该字段为 true。恢复基础皮肤不会撤销 PIN；提示明确要求退出当前游戏进程释放。没有尝试强制释放仍被游戏引用的模块。其他情况也只提示“模块卸载尚未核验”，不伪报完整卸载成功。

原版一的换肤卸载按钮和成功/失败分支此前有静态证据；完整游戏模块卸载的效果未动态确认，本次没有直接复制未确认的驱动卸载接口，也没有加入日志清理操作。

本轮原生编译和已有内存夹具测试通过；服务 22 项定向测试、UI 9 项定向测试通过，覆盖排队请求失效、新请求拒绝、恢复未核验、结果不明及设置关闭。深浅主题预览已生成并检查。实际游戏内恢复与驻留释放尚未完成实测，不能标记完整卸载验收通过。

运行包：artifacts/skin-integration/LOL-GameGUI.exe，需保留同目录 Tools/SkinCore。旧对局可能使用已加载的旧核心，需结束旧对局并使用新版开启新局。验收时先换肤，再点“恢复并停用”，检查基础模型和重新释放的技能/回城效果，并确认开关、列表及快捷键已停用。
