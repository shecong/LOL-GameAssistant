# 换肤菜单与开关交付记录

日期：2026-10-10。

本次新增主导航“游戏换肤”，使用项目现有 AntdUI 的 Panel、Switch、Input、Select、Button 和 Label，跟随深浅主题及中英文切换。开关默认关闭，并通过既有设置存储保存。仅打开功能且页面可见时连接核心、刷新当前英雄和皮肤目录；助手启动时不自动执行换肤。

功能包括搜索皮肤与模型、选择具体形态条目、手动应用、恢复基础皮肤。页面内容居中并限制最大宽度，标题和开关对齐，下拉框高度 56，最多显示 12 项；周期状态读取不会主动关闭下拉框。关闭功能停止页面请求并失效排队选择；对局结束清空目录。原生动作一旦开始，关闭或超时不能保证撤回，界面会提示结果未确认，不自动重试。没有强制卸载游戏内模块，也不会在关闭时自动还原皮肤。

新增独立的游戏快捷键设置卡片，默认关闭，支持组合键录制、冲突校验与持久保存。默认上一款 Ctrl+Alt+Left、下一款 Ctrl+Alt+Right、应用所选 Ctrl+Alt+Enter。使用既有 Windows 按键处理，仅游戏前台且对局进行中生效；助手页面隐藏时仍可使用。循环依据实际状态和完整数据库条目（区分重复编号和形态），应用所选要求对局会话一致。750 毫秒限流，已有请求执行时忽略新增按键；关闭、结束对局或变更设置会失效待执行请求。

核心接口由 C# 串行服务调用 x64 原生命令行主机，配套 DLL 置于 Tools/SkinCore。无需 Python 或原版小助手；原生源码、构建来源和许可证已复制到仓库 native/LeagueSkinCore，重新构建可执行 tools/build-skin-core.ps1 -Rebuild -Test。单文件发布的主 EXE 与外置 Tools/SkinCore 必须一起保留。
