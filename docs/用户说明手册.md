## 首次使用与客户端连接

1. 启动英雄联盟客户端，完成登录，再启动助手；也可以先启动助手，等待客户端登录。
2. 首页显示当前玩家资料后，即可使用战绩、好友和客户端相关功能。
3. 如需由助手启动客户端，进入 **设置 → 客户端与数据**，选择 LOL 安装文件夹，点击 **立即启动 LOL**。
4. 如需每次打开助手时启动客户端，开启 **启动助手时直接启动 LOL 客户端**，点击 **保存客户端设置**。

安装路径可以留空，让助手尝试查找。启动器要求登录或更新时，需在启动器完成相应操作；助手不会代替账号登录。

部分功能只在对应阶段可用：例如应用选人方案需要进入选人阶段，海克斯侧边栏需要进入海克斯大乱斗对局。操作结果以页面中的状态提示为准。

## 首页：个人资料与排位信息

**入口：首页。**

首页显示玩家名称、标签、等级、升级所需经验、排位信息及近期战绩。也可以通过首页搜索框查询其他玩家资料。

排位卡片分为 **单双排** 和 **灵活组排**，可查看段位、胜率、胜场、负场、LP 和最高段位。卡片下方补充定级赛、晋级赛、总场数及赛季结束信息。

“未排位”表示当前返回的数据中没有有效段位；“－”表示该项暂未取得。隐藏分等字段以客户端返回值为准，缺失时不会自行推算。

近期战绩中可查看英雄、胜负和 KDA；双击近期战绩行可打开对局详情。

## 好友：状态、战绩与观战

**入口：好友。**

1. 打开好友页，点击 **刷新** 读取当前账号的好友列表。
2. 查看好友在线状态及当前游戏状态；悬停可查看补充信息。
3. 双击好友头像，进入该好友的战绩查询。
4. 好友处于可观战的对局时，点击卡片中的观战按钮，由客户端发起观战。

观战是否可用取决于好友当前对局及客户端返回状态。列表为空时，先确认客户端已登录，再刷新。

## 对局：双方阵容与近期表现

**入口：对局。** 大厅、选人和游戏进行中会根据当前可取得的信息展示玩家。

页面按蓝方、红方分组，标注我方或敌方。玩家卡片展示头像、名称、等级、段位、当前英雄、近期战绩及表现标签；可用空间足够时展示战绩汇总。

| 操作 | 作用 |
| --- | --- |
| 单击玩家身份区域，包括头像、名称、段位或当前英雄 | 复制玩家 ID（PUUID，玩家唯一标识） |
| 双击同一身份区域 | 打开该玩家的战绩查询 |
| 双击卡片内的一条近期战绩 | 打开该场对局详情 |
| 点击“回到顶部” | 将队伍列表与卡片内战绩列表返回顶部 |
| 点击主界面“刷新” | 重新读取当前页面相关数据 |

单击复制会短暂等待，以区分单击和双击。机器人或缺少玩家 ID 时，身份操作可能不可用。

**开黑标记：**“开黑”表示已取得本局组队信息；“疑似开黑”依据近期同队记录推断。悬停标记可查看成员和判断说明，推断结果不能作为本局组队的确认。

**近期表现：**KDA 评估统计最近 30 天内同模式的有效对局，满 5 场后按累计 KDA 分档；不足 5 场显示样本不足。标签用于参考近期表现。

在 **设置 → 对局自动化** 可开启自动刷新并设置间隔，最小为 10 秒。定时刷新在对局页处于当前标签页时执行；相同阵容保留已加载卡片，英雄与组队标记原位更新。

## 战绩查询：记录、统计、收藏与导出

**入口：战绩查询。**

### 查询玩家

1. 输入 **名称#TAG** 或 **PUUID**，点击 **查询**。
2. 查询自己时，可直接点击 **我的战绩**。
3. 查询成功后查看玩家资料及单双排、灵活组排信息。

点击资料区的玩家名称可复制名称，点击标签可复制对应 ID 文本。

### 对局记录与统计

- **对局记录**：通过分页查看战绩，每页可选 10、20 或 50 条；点击记录卡片的详情按钮查看完整对局。
- **数据统计**：查看胜率、平均 KDA、常用英雄等汇总，并按模式筛选。统计以已取得的战绩数据为基础。
- **回到顶部**：回到记录列表顶部。详情补齐时会保留当前阅读位置。

### 收藏与导出

- 查询玩家后点击 **☆ 收藏** 保存查询对象；已收藏玩家可通过收藏列表选中并点击 **加载**。
- 点击 **导出战绩**，选择 CSV 保存位置。程序会尝试获取该玩家全部可取得的战绩，导出对局 ID、模式、日期、时长、英雄、胜负、KDA、补刀、伤害、金币、视野和装备等字段。

导出数量取决于客户端能够提供的历史记录，不限于当前显示的一页。

## 对局详情：装备、符文与增幅作用

**入口：近期战绩行的双击操作，或战绩记录卡片中的详情按钮。**

详情窗口标题展示模式、胜负和时长。双方玩家分栏展示英雄、KDA、伤害、补刀、装备、召唤师技能，以及可取得的符文或增幅信息。

- 将鼠标停在装备、符文或增幅上，查看名称和作用说明。
- 点击已加载说明的条目，打开详细说明窗口；长说明可以滚动阅读。
- 查看详情下方的玩家数据，了解等级、金币、承受伤害、治疗、视野、多杀等信息。
- 部分战绩卡片中的玩家身份支持双击，便于继续查询该玩家。

图标或说明未加载完成时稍候再试；客户端或资源数据缺失时，可能只能显示名称或 ID。

## 匹配、选人与赛后自动化

**入口：设置 → 对局自动化。** 本页开关、延迟、队列及英雄列表会自动保存。

| 功能 | 使用方法与效果 |
| --- | --- |
| 自动匹配 | 回到大厅后尝试开始匹配 |
| 自动接受 | 匹配确认出现后自动接受；可配置最小、最大延迟，均为 0 时立即接受 |
| 自动禁英雄 | 开启后设置禁用列表，在本人的禁用阶段按列表顺序尝试 |
| 自动选英雄 | 设置选用列表，在本人的选用阶段按列表顺序尝试 |
| 仅预选，不锁定 | 开启后保留手动锁定操作 |
| 补位跳过选人 | 客户端明确标记补位时，跳过自动选人 |
| 大乱斗自动交换 | 按备战席优先级选择更高优先级的英雄 |
| 自动点赞 | 赛后尝试执行点赞操作 |
| 自动返回大厅 | 赛后尝试返回大厅 |
| 返回后继续匹配 | 需同时开启自动返回大厅，返回后尝试开始匹配 |
| 对局结束提醒 | 对局结束后显示托盘提醒并写入消息区 |

英雄列表中的顺序决定尝试优先级。备战席列表按选取顺序排列；取消后重新选择可调整顺序。

本页还提供 **快速创建大厅**、**取消当前匹配**、**退出英雄选择**。快速创建大厅使用上方队列 ID，默认 430；这些操作是否成功取决于客户端当前阶段和允许的操作，以结果提示为准。

## 选人伴随窗与备战席交换

**开启入口：设置 → AI 与推荐 → 选人时在客户端侧边显示队友伴随窗。** 保存 AI 设置后生效。

选人时，伴随窗贴在客户端侧边，随客户端移动、缩放和最小化。窗口展示可见队友的段位、近期表现及自动选禁状态。

- 点击 **一键选择符文装备**，按当前英雄、模式和位置打开方案选择窗口。
- 大乱斗或海克斯大乱斗出现备战席时，查看可交换英雄，点击英雄执行交换。
- 想自动交换时，在 **设置 → 对局自动化** 开启相应选项并设置优先级。

英雄选择及备战席信息会持续更新；英雄不可交换或已被其他玩家取走时，以客户端反馈为准。

## 出装与符文推荐

**手动入口：智能建议 → OP.GG 一键配置当前英雄。**

**自动展示入口：设置 → AI 与推荐 → 启用 OP.GG 选人出装与符文推荐。**

1. 在选人阶段选择英雄。
2. 打开推荐窗口，核对英雄、模式和分路，浏览推荐方案。
3. 选中方案后点击应用，查看操作结果，并在客户端确认符文、召唤师技能和物品集。

浏览推荐本身不会写入客户端。只有符合当前选人场景的方案可以应用；浏览其他模式后，应切回当前对局模式再应用。

**符文页已满时：**程序可复用助手创建的符文页。方案窗口另有 **允许覆盖当前自定义符文页** 选项；不希望覆盖自己的当前页时取消勾选，并在客户端释放符文页额度。替换失败会尝试恢复，最终状态以结果提示和客户端实际页面为准。

海克斯大乱斗使用专用出装、召唤师技能及增幅统计，不应用常规符文页，保留客户端当前符文。

## 我的符文方案

**入口：智能建议 → 我的符文方案。**

### 保存个人方案

1. 进入选人阶段，选择英雄，并在客户端调整好当前符文页与召唤师技能。
2. 打开 **我的符文方案**，点击 **从当前选人捕获**。
3. 设置方案名称、模式、分路和优先级；数值越高越优先。
4. 需要自动使用时勾选 **选人时自动使用**，点击 **保存修改**。

### 使用与管理

- 选中方案，点击 **立即应用**，用于当前可应用的选人场景。
- 修改名称、优先级或自动使用状态后，点击 **保存修改**。
- 不再需要时选中方案，点击 **删除方案**。

自动应用还需在 **设置 → AI 与推荐** 开启 **选人自动应用个人符文；无匹配时使用 OP.GG** 并保存。助手按英雄、模式和分路匹配个人方案；没有匹配方案时使用对应模式推荐。峡谷模式需要留意分路匹配。

## 海克斯大乱斗增幅侧边栏

**开启入口：设置 → AI 与推荐 → 海克斯大乱斗显示局内增幅侧边栏。** 保存后，在对应对局中显示。

1. 进入海克斯大乱斗，查看当前英雄的增幅推荐。
2. 用 **白银 / 黄金 / 棱彩** 切换类别；每类独立按英雄样本胜率排序。
3. 游戏中出现待选增幅卡片时，点击 **扫描当前增幅**。
4. 在识别结果中查看增幅类型、推荐顺序、胜率及样本量；无对应样本时会标注。

侧栏也会定期扫描。收起后，识别到新一轮增幅时可能自动展开，便于查看新选择。

**窗口操作：**点击标题或 × 收起，点击收起后的标题展开；拖动标题可调整位置。侧栏显示、收起及点击操作不会抢占游戏输入焦点。

扫描使用本机截图与 OCR，截图在内存中处理。识别模型已内置，无需另放 OCR DLL 或语言数据文件。游戏窗口需能正常截屏，推荐使用窗口或无边框模式；卡片应清晰可见。识别结果用于辅助比较，最终选择前请核对游戏里的实际名称。

## AI 时间线建议

**配置入口：设置 → AI 与推荐。查看入口：智能建议。**

1. 选择服务商，填写 API Key、接口地址与模型名称。
2. 可点击 **获取可用模型** 读取模型列表，或点击 **测试连接** 验证当前填写内容。
3. 开启 **启用 AI 时间线建议**，按需设置游戏中自动刷新、间隔、提醒和游戏内建议浮窗。
4. 点击 **保存 AI 设置**。
5. 在智能建议页查看建议及状态，需要重新生成时点击 **立即更新建议**。

游戏内建议浮窗可配置位置、横向和纵向偏移及停留时间。即使未打开智能建议页，启用的后台刷新仍可更新建议。

**数据说明：**开启并保存后，生成建议会把当前英雄、游戏阶段、可见阵容、游戏时间、金币与已购装备发送给所选 AI 服务商；不会发送 LCU Token、账号密码、玩家身份或本机聊天内容。未配置密钥或模型时不会发起建议请求。

密钥加密保存在当前 Windows 用户下。密钥输入框留空表示保留原密钥；需要删除时点击 **清除已保存密钥**，再保存。

## 喊话与 KDA 发送

**入口：设置 → 喊话。**

### 词库与发送

1. 从默认词库选择短句，或在自定义词库中按 **一行一句** 填写。
2. 开启 **多选** 可按词库顺序选择多句；先查看待发送内容预览。
3. 按需选择发送给所有人、粘贴输入、逐字发送及发送间隔。
4. 点击 **保存设置** 保存词库和发送选项。
5. 点击 **发送到客户端群聊** 或 **一键发送到游戏**。

一次最多发送 10 句，自定义词条每句最多 500 字。游戏内发送需要当前游戏聊天可用；遇到输入问题可先使用 **测试游戏回车**。

### 近期 KDA 评估

在 **设置 → AI 与推荐** 可分别开启：

- **选人 KDA 发送**：我方数据加载完成后，通过客户端聊天发送一次；模板支持 `{players}` 和 `{allies}`，两者均代表我方名单。
- **对局 KDA 发送**：双方数据加载完成后，按喊话页的发送方式发送，一局一次。
- **单人一行**：每名玩家发送一条；未勾选时默认蓝方、红方各一条。同时影响手动发送。

关闭自动发送后，仍可在喊话页启用手动 KDA 快捷键。**自定义测评文案** 用于小键盘逐人发送，保存后下一次发送即使用。

### 默认游戏快捷键

下列快捷键需先启用对应选项并保存，仅游戏处于前台时响应。

| 按键 | 功能 |
| --- | --- |
| F6 | 从默认词库随机发送 |
| F7 | 从自定义词库随机发送 |
| F8 | 发送当前选中的短句，支持多选 |
| F9 | 手动发送双方近期 KDA 评估，可重复发送 |
| 小键盘 1–5 | 逐人发送蓝方五人的测评 |
| 小键盘 6–9、0 | 逐人发送红方五人的测评 |

小键盘映射按卡片从左到右、从上到下排序，需开启 Num Lock。F6–F9 可在输入框中录入新按键，支持 Ctrl、Alt、Shift 组合；启用的热键不能相互重复或与按住置顶键冲突。

## 客户端工具

**入口：设置 → 客户端工具。** 所有操作作用于本机当前登录的客户端。

| 分类 | 功能与步骤 |
| --- | --- |
| 回放与备份：对局回放 | 输入对局 ID，点击“下载回放”，取得回放后点击“观看回放”；可用性取决于客户端和回放状态 |
| 回放与备份：待领取奖励 | 点击“一键领取待选奖励”，查看返回结果 |
| 回放与备份：游戏设置备份 | 输入备份名称，保存当前游戏设置；之后从列表选择备份进行恢复或删除 |
| 资料与外观：在线状态 | 选择状态并输入状态文案，点击“更新在线状态” |
| 资料与外观：挑战角标 | 点击“清除挑战角标” |
| 资料与外观：生涯背景、头像 | 输入 ID 后预览，或点击“浏览选择”；选择只回填 ID，点击“应用背景 / 应用头像”才写入客户端 |
| 好友活动 | 点击“刷新好友活动”，查看好友队列状态、游戏时长和组色标记 |
| 英雄数据 | 选择模式，读取英雄 T 级，或读取极地大乱斗平衡修正 |

浏览背景和头像时，可按名称或 ID 搜索，点击 **加载更多** 获取下一页缩略图。是否能应用取决于客户端对相应资源的支持，以操作结果为准。

## 外观、窗口与快捷键

**入口：设置 → 外观与窗口。** 修改后点击 **保存窗口设置**。

- **主题**：跟随系统、浅色或深色；主界面主题按钮也可快速切换。
- **语言**：中文或 English，保存后立即切换。
- **透明度**：40%–100%，数值越小越透明。
- **按住置顶键**：点击输入框录入按键，默认是键盘左上角的 · / ` 键。按住时临时显示并置顶助手，松开后隐藏到托盘，不抢游戏焦点。
- **仅在 LOL 位于前台时响应**：限制按住置顶键的响应范围。
- **局内对局信息面板**：默认开启。游戏位于前台时按住 **· / `** 键显示独立的蓝红双方列表，松开按键或切出游戏后隐藏；不会激活助手或抢走游戏鼠标输入。可录入单键或 Ctrl / Alt / Shift 组合键，点击 **保存窗口设置** 生效。不能与已启用的喊话或 KDA 快捷键冲突。在客户端或桌面仍使用原来的按住置顶键。请使用游戏窗口或无边框模式，独占全屏下不保证可见。
- **面板数据口径**：段位、赛季场次和胜率来自排位数据，灵活组排显示灵活段位，其余模式显示单双排段位。英雄胜率来自最近100场战绩中同模式、同英雄的有效对局，同时显示样本数；近期胜负和 KDA 最多统计10场同模式有效对局，重开及缺失统计不计入。实时列显示本局 KDA、补刀和视野得分，接口未提供的插眼次数不会以视野得分代替；缺失数据显示为 **—**。
- **最小化到托盘**：开启后点击关闭会隐藏到托盘，单击托盘图标恢复；需退出时右击托盘图标选择 **退出**。关闭该设置后，关闭窗口会退出程序。
- **游戏分辨率**：保存所选尺寸，并调整助手主窗口大小；不会修改游戏本身的画面分辨率。

Windows 开机自启在 **设置 → 客户端与数据** 配置，保存客户端设置后生效。

## 日志与运行诊断

**日志页** 查看运行消息、异常及连接相关信息。

**运行诊断页** 查看组件、状态、详情和更新时间，适合检查客户端连接、启动、热键和自动化状态。将鼠标停在顶部说明上，可查看诊断日志路径。

反馈问题时，记录操作步骤、出现问题的页面、当时游戏阶段及对应诊断信息。分享普通日志前检查是否包含不希望公开的本地信息。运行诊断日志不记录 LCU Token、聊天内容或 API Key。

**关于页** 可查看项目介绍、仓库入口及交流信息。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 首页一直等待客户端 | 确认客户端已启动并登录；查看运行诊断中的连接状态；自动启动失败时检查安装文件夹 |
| 查询不到玩家 | 使用完整“名称#TAG”或 PUUID，确认输入无多余空格，并检查客户端连接 |
| 战绩、段位或图标暂缺 | 等待数据加载，再刷新；“－”不代表数值为 0，可能是客户端尚未返回 |
| 点击玩家后稍等才复制 | 单击会等待双击判定；双击身份区域会查战绩，双击战绩行会打开详情 |
| 自动选禁没有动作 | 检查开关、英雄列表和本人当前动作阶段；同时检查是否开启仅预选或补位跳过 |
| 推荐只能看，不能应用 | 确认处于选人阶段、已经选定英雄，并切回当前对局的模式 |
| 符文页满了 | 释放客户端符文页额度，或核对方案窗口的允许覆盖当前页选项；操作后检查客户端当前页 |
| 海克斯侧栏没有出现 | 确认局内侧栏开关已保存，且当前对局是支持的海克斯大乱斗模式 |
| 增幅扫描为空或识别不准 | 使用窗口或无边框模式，确保待选卡片清晰可见，重新扫描并核对名称 |
| AI 没有生成建议 | 检查总开关、密钥、接口和模型，测试连接，保存后查看智能建议页状态 |
| 游戏快捷键无反应 | 确认对应选项已启用并保存，游戏在前台，热键无冲突；小键盘还需开启 Num Lock |
| 修改设置后没有生效 | 对局自动化页自动保存；客户端、窗口、AI 和喊话设置使用对应保存按钮 |
| 关闭窗口后程序还在 | 开启了托盘设置；单击托盘图标恢复，或右击托盘图标选择“退出” |
