# 资源包加载组件

原始输入来自用户提供的 `E:\迅雷下载\换肤\HID.dll`，SHA256：

`E4FBBF9671303712A764D505D9E9A6C5FAE7004873899255AB798F759D23E69B`

通过 `tools/prepare-resource-skins.ps1 -Source <HID.dll 路径> -Python <python.exe>` 准备；生成的组件补充 Windows HID 接口转发并停用附加广告线程，固定 SHA256 为 `DA1B89FB914992D012AEBF5557C41274497463A7A5D2CB8ECFACEE51F872A3E4`。构建时需要 Python pefile，运行程序不需要。构建和发布自动复制至同名 Tools 目录；系统 HID 接口提供文件由安装步骤从本机 Windows 目录复制。

点击「安装加载组件」或首次挂载时，助手仅在对局外将经过哈希校验的文件复制到所选 Game 目录。已知旧版归档后升级，未知 HID.dll 会被保留并报错，不覆盖。关闭资源包模式时将已知加载器重命名为停用备份，不删除；单独清理资源只移除本助手 WAD。仅安装文件，不修改注册表或游戏的其他 DLL；兼容性需实机验证。

安装按钮仅在资源包模式启用时可用，避免在其他换肤模式下留下活动 HID。原版创建的英文 Game 路径别名会先解析为真实目录，挂载清单记录真实路径；资源目录内部的联接或符号链接仍会被拒绝。

资源文件必须在游戏进程启动前准备好。`.wad.client` 保留明文格式并检查 WAD v3 条目范围；`.riftmod.client` 保留该后缀，非空的加密内容不按明文解析，条目数量显示为“加密包”。下载仍检查长度及仓库提供的 Git blob 哈希，清理仅处理清单中内容哈希未变化的助手文件。

“已准备”仅表示文件写入完成，不代表加载器已在游戏内替换资源。2026-11-07 的亚索黑夜特效包视觉验收仍未通过，不能把导入、下载或清理测试作为换肤效果通过的证明。
