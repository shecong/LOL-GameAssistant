# sc助手客户端视觉组件 v0.4.0

内核版本：1.2.0；源码提交：2ea9bae047a2218459786971b0e304755d738a97；平台：Windows x64。

解压到一个新目录。在更新后的 sc助手中打开：设置 → 客户端工具 → 资料与外观 → 客户端视觉插件。
选择本包的 PenguLoader 根目录，点击“激活客户端加载”，完整重启 LOL 客户端。
之后在 sc助手中选择本地图片或图片直链、切换导航/评级/选人信息开关，点击“应用设置”。
“检查加载状态”应显示“客户端已连接 sc助手控制 · 设置已应用”。日常修改设置无需打开 Pengu 管理窗口。

本包只包含已构建的组件及安装所需元数据，不包含完整开发源码；需要构建时请克隆对应源码提交。
不携带本机配置、壁纸、账号、令牌、datastore 或 runtime.json；保留用户已有配置请勿覆盖旧目录。

完整管理界面包额外包含 bin/pengu-loader.exe。可在 Settings → Pengu Loader 中切换简体中文。
管理界面用于查看和管理插件；本仓库视觉插件的具体设置仍由 sc助手控制。

纯插件 ZIP 解压后，将 lol-game-assistant-visuals 文件夹放入已有 Loader 的 plugins 文件夹。
已有原版内核时保留客户端内设置面板；使用 sc助手直接控制需要本包的定制内核与更新后的 sc助手。
