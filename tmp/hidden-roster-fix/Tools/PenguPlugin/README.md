# 客户端视觉插件 v0.4.5

由 sc助手直接控制英雄评级、选人开黑 / KDA / 胜率、英雄克制悬停卡片、隐藏导航和壁纸。日常运行不需要 Pengu 管理窗口、Vite 服务或 WebView 前端。视觉内核可从 [Gitee 发行版](https://gitee.com/sc_c/PenguLoader/releases/tag/visuals-v0.4.0) 安装，也支持用户本地构建的 core.dll。

## 使用

1. 在 sc助手的视觉插件设置中点击“从 Gitee 安装 / 更新视觉组件”，下载安装已固定版本并通过 SHA-256 校验的精简包。切换内核时保留原插件目录、壁纸和客户端选项。也可从 Gitee 手动下载并解压，再点击“选择本地组件 / 源码目录”；自行构建时运行 `./scripts/prepare-game-assistant.ps1 -BuildCore`。
2. 在 sc助手的“设置 → 客户端工具 → 资料与外观 → 客户端视觉插件（Pengu）”，点击“激活客户端加载”。这会安装视觉插件并直接配置本地 core.dll 的加载入口。
3. 完整重启 LOL 客户端一次。此后修改开关或壁纸自动保存，客户端约 1 秒内读取；不需要每次重启。
4. “检查加载状态”显示内核、插件和有效状态回传。“停用客户端加载”下次启动生效；取消“启用视觉功能”可实时恢复客户端默认视觉。

首次接入或更新 core.dll 后必须重启客户端才能加载新内核。设置更改和内核升级是两种不同的生效过程。客户端内不再挂载本插件的设置面板。

sc助手也提供本地内核的五个原生选项：客户端优化、低配模式、静默模式、Riot Client API、不安全模式。勾选自动保存到本地 `bin/config`，完整重启 LOL 客户端后生效；它们独立于“启用视觉功能”总开关。保留原有插件目录及其他内核配置，不需要运行 Pengu 管理前端。不安全模式关闭网页安全限制；兼容本地内核历史配置键 `isecure_mode` 与管理界面键 `insecure_mode`。

## 设置与状态通道

sc助手原子写入 `bin/plugins/lol-game-assistant-visuals/settings.json`（遵循本地 `[app] plugins_dir` 配置）。客户端 preload 仅向此插件注入 `visualControl`，通过固定路径、限长的 native 方法读取设置，每秒检查一次。应用后及每 10 秒写入 `runtime.json`，含配置 revision、加载状态、模式、头像/角标数量和壁纸/配置错误。助手只接受 35 秒内的活动状态；心跳不代表所有客户端页面均兼容。

桥接不提供任意文件路径读写。心跳不包含账号令牌、聊天或玩家身份。关闭 sc助手后，文件配置仍保留并由客户端继续使用。未迁移的旧内核仍保留旧面板兼容入口，更新内核后进入直接控制模式。

壁纸支持 HTTP/HTTPS 图片直链，Unsplash `/photos/` 网页会明确提示使用直链。也可在 sc助手选择 JPG、PNG、BMP、GIF 本地图片（最多 20 MB，GIF 使用静态帧），规范化为最长边 2560 像素的 PNG 后复制到插件目录，原图移动或删除不影响壁纸，不上传图片。图片成功加载后才透明化原背景；切换导航开关不会清除壁纸。壁纸开关可立即恢复原背景并保留图片；重新开启后恢复图片。清除壁纸会删除图片设置。

## 数据

英雄 T 级取 OP.GG 公开统计，自动识别峡谷（训练模式使用峡谷参考评级）、大乱斗、斗魂竞技场、无限火力，可手动指定；缓存 30 分钟。失败退避重试，切换模式不会被过期请求覆盖。

选人信息只读本机 LCU：按 cellId/puuid 等识别队伍行，相同有效 partyId 显示开黑分组；标识缺失时合并每位玩家近期最多20场战绩的 gameId 和 teamId，整组共同同队至少2场才显示“疑似开黑”。不把关系链合并成多人组，不跨当前阵营分组，明确不同 partyId 不采用推断。没有识别依据时隐藏开黑行，保留 KDA 和胜率。推断不代表确认本局预组队。由 sc助手控制时，KDA 和胜率直接使用助手发往选人聊天的同一份评估结果：最近50场有效记录，优先同队列，无同队列样本时采用全模式参考，小数截断和胜率格式与聊天完全一致。结果按我方名单、队列和有效期校验，等待结果或身份隐藏时显示未知，不使用另一套统计补位。独立运行时保留最近20场本机战绩参考；开黑推断的20场样本不改变托管统计口径。排除自定义、重开、不足 5 分钟及缺失数据；身份隐藏时显示未知，不绕过隐藏身份。此数据是玩家近期数据，并非选定英雄专属胜率。

悬停英雄头像会显示 OP.GG 峡谷分路对位数据，可切换分路；分为克制他的英雄、他克制的英雄，每组至多5位，仅纳入至少100场有效对位，胜率统一为列表英雄对悬停英雄的胜率。其他模式无对应对位统计时不显示峡谷推荐。数据缓存30分钟。开启“英雄克制”时隐藏原生英雄技能预览浮层并暂停其中的视频，关闭开关恢复原生浮层；英雄背景及壁纸不受影响。

卡片的“选用”按钮调用与助手自动选人相同的本机 LCU PATCH `/lol-champ-select/v1/session/actions/{id}` 接口，只预选、不锁定。请求前重新确认本地玩家动作、是否轮到选人、可用英雄、禁用和选用状态；悬停与读取统计不写入 LCU。不同版本客户端的头像选择器仍需在选人页面实测。

## 验证

`npm test --prefix PenguPlugin` 运行浏览器 DOM 和缓存竞态测试；浏览器依赖使用 `npm ci --prefix PenguPlugin` 和 `node PenguPlugin/node_modules/playwright/cli.js install chromium` 安装。包括直接控制、坏配置保留上次状态、导航/壁纸独立、关闭功能和卸载清理。
