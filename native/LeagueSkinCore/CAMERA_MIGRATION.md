# 无限视距移植

2026-10-22：已接入皮肤修改页第三个菜单“其他设置”和 Home 局内面板。无限视距开关可在局外预先设置并持久保存；开启时一并启用独立核心。首次连接且没有历史记录时只读当前默认值，不写入固定的 1700。局内滚轮每格调整缩放上限 18（原为 60，降低 70%），范围 600–1700；核验成功后写入设置，下局自动应用。关闭无限视距恢复本局首次读取值，保留历史记录供再次开启使用。独立核心总开关关闭时同时清除无限视距启用标记，避免重启后重新启用。

滚轮只在游戏前台、鼠标位于交互面板外时记录，滚轮消息及原始输入均按原值的 30% 交给游戏，小增量保留余数；滚动 Home 皮肤列表不调整视距。Home 面板隐藏后继续记录。缓存对应当前已验证的相机配置缩放上限，手动恢复时同步恢复游戏原本镜头距离。写入结果未确认时停止自动调整，不覆盖历史距离；用户可以重新读取或关闭恢复。首次自动读取遇到游戏窗口/相机尚未就绪可重试，写入失败不自动重试。

按下鼠标滚轮中键与关闭无限视距均恢复首次读取的缩放配置，并将当前镜头距离和目标距离恢复为游戏配置 `+0x28` 的原本距离（不再写死为 600）。中键保持无限视距开关开启，两种操作都保留历史记录。恢复顺序为缩放配置、实际镜头，两个阶段均需读回核验；实际镜头阶段失败时保留待恢复标记，允许手动重试。游戏前台且鼠标位于交互面板外时生效，Home 面板隐藏后仍可使用。

实际镜头适配依据保存的当前版本代码：`0x65ae96` 通过全局槽 `0x1c7c020` → 管理器 `+0x18` 读取镜头；构造器 `0x98a028` 将配置 `+0x28` 同时赋给镜头 `+0x3c0` 当前距离和 `+0x3c4` 目标距离，滚轮处理 `0x9a7ac7` 修改后者。新接口验证这两段代码指纹、镜头关联配置对象和会话，在游戏线程中以一次 8 字节比较交换更新当前值和目标值，再分别读回核验。单独的实际镜头接口不改配置字段 `+0x20`；完整恢复另行恢复该配置。脚本镜头锁定或指纹不符时拒绝写入。此实际镜头路径通过离线内存、配置不变、相邻字段、过期状态和指纹拒绝测试，尚未进行运行中游戏的画面验收。

- `camera-status`：读当前值、会话、配置对象身份。
- `camera <session> <distance> <expected-distance>`：验证范围、会话、可写内存，并以原子比较交换写一个 float。状态变化时拒绝覆盖。
