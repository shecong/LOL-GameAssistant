# LOL 对局小助手

这是一个围绕英雄联盟客户端信息制作的小工具。它的初衷很简单：把排队、进入对局和查看战绩时常用的信息放在一起，少一些来回切换和手动查询。

项目还在持续完善中。目前的功能或许不算复杂，但希望能让查看对局信息这件事更顺手一些。

## 功能一览

目前应用分为六个页面：首页、对局、战绩查询、关于、设置和日志。

### 首页

可以快速查看自己的段位和近期战绩，也支持搜索其他玩家的基础信息。

### 对局

进入对局后，可查看当前对局中所有玩家的战绩信息，并展示各自最近九场对局记录，方便在开局前有一个大致了解。

### 战绩查询

用于展示个人更详细的战绩内容。目前基础页面已完成，具体的信息呈现和布局仍在逐步完善。

### 关于

介绍项目的背景、功能方向，以及项目仓库地址。

### 设置

可以按自己的使用习惯调整以下选项：

* 自动匹配对局
* 自动接受对局
* 自动禁用英雄
* 自动选择英雄
* 定时检查间隔

其中自动禁用和自动选择英雄仍在开发中，暂未作为稳定功能提供。

### 日志

记录软件运行时的异常和客户端连接诊断信息，便于定位问题。日志可能含有本地敏感信息，如需分享给他人排查，请先确认内容已做必要处理。

## 正在完善的内容

当前客户端通信主要通过轮询实现。后续计划尝试改为 WebSocket 通信，以减少不必要的 HTTP 请求，让状态更新更及时。

另外，自动禁用和自动选择英雄功能仍需完善；个人详细战绩页面也还在思考更合适的展示方式。这些内容会随着项目的使用和反馈慢慢迭代。

## 后续想法

之后希望研究更完整的客户端登录流程，尝试把常用的客户端操作整合到工具中；也会考虑加入出装、符文推荐等更贴近实战的信息展示。

关于外观相关能力，目前也还停留在研究阶段，会优先关注安全性、稳定性以及是否符合客户端规则。

## 项目地址
