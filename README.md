# LOL 对局小助手

**选人配符文，局内看信息，赛后查战绩。把玩 LOL 时常用的辅助功能集中到一个窗口里。**

LOL 对局小助手是一款 Windows 桌面工具。打开并登录英雄联盟客户端后，助手会识别当前的游戏状态，在选人、对局和赛后提供对应功能。

你可以只用它查战绩，也可以开启自己需要的选人辅助、符文装备配置、局内信息面板、复盘、奖励兑换和组队功能。常规查询、符文推荐和奖励工具不需要配置 AI。

📖 **第一次使用，直接看 [完整玩家使用指南](docs/玩家使用指南.md)。**

## 它能帮你做什么

| 使用场景 | 能做的事 |
| --- | --- |
| 开始游戏前 | 启动 LOL、查看自己的段位和近期战绩、查看好友活动、创建开黑大厅 |
| 匹配与选人 | 自动接受、按优先级选禁、只预选不锁定、查看队友近况、大乱斗备战席自动换英雄 |
| 准备符文装备 | 预选、选定或更换英雄时自动配置；也可手动选择推荐方案，保存自己的符文和出装 |
| 游戏进行中 | 按住快捷键查看双方信息；海克斯大乱斗查看增幅推荐、扫描当前三张增幅卡片 |
| 想交流或发战绩 | 一键喊话、自定义短句、快捷键发送近期 KDA，按需开启自动发送 |
| 打完一局 | 查对局详情、比较近期数据、标记复盘笔记、设置练习目标、管理主练英雄 |
| 领取与兑换 | 扫描可领取奖励、选择待选奖励、按类型勾选魄罗商品、后台兑换并接收完成通知 |
| 找队友 | 在休息室聊天、发布或报名开黑招募、收藏常用队友，再通过 LOL 客户端组队 |
| 管理客户端 | 下载与观看回放、备份游戏和按键设置、调整在线状态与生涯资料、清理缓存 |
| 需要更多建议 | 自行配置 AI 服务，查看本局行动建议和建议记录 |

## 几个实用功能

### 选到英雄，就能准备符文和装备

开启“符文装备自动配置”后，助手会根据预选或已选英雄、模式和分路应用方案。换了英雄，也会跟着更新。

有匹配的个人方案时优先使用个人方案；没有时使用推荐方案。个人方案没有保存装备时，可以补充推荐出装。你也可以点击“一键选择符文装备”手动挑选。

装备配置会写入客户端的自定义物品集，进游戏后在商店查看，购买仍由你操作。

### 游戏里按住一个键，查看双方近况

默认按住键盘左上角的反引号键（通常和 `~` 在同一键位，界面中显示为“· 键”），可以查看双方信息。松开后收起，方便边打边看。

对局页面还有经典卡片、双队总览、位置对位等布局，可以按自己的习惯切换。

### 大乱斗准备更方便

普通大乱斗和海克斯大乱斗都可以在选人伴随窗里查看备战席。设置英雄优先级后，出现更想玩的英雄时可以自动交换。

海克斯大乱斗还能查看增幅统计、扫描当前三张卡片并校正识别结果。最终选择哪张增幅，由你决定。

### 魄罗商店不用守着兑换

“兑换全部数量”默认勾选，会按限购和余额计算可兑换数量；取消后可以手动填写。

支持分别全选皮肤碎片、英雄碎片、图标、表情、守卫皮肤、炫彩等类型。提交后可以关闭商店窗口或切换页面，兑换会在助手后台继续。完成后有提示，重新打开还能查看本次结果。

### 复盘从一个小目标开始

除了查看输赢，还可以查看补刀、伤害、视野等数据，给某一局写下笔记，标记主练英雄，或者设置一个下一阶段的练习目标。

“一分钟复盘”会根据已有战绩给出值得保持、值得关注和下一局可以尝试的目标。它比较的是实际取得的数据，不会凭战绩猜测整局发生了什么。

## 怎么开始

1. 下载并完整解压发布包，运行 `sc助手.exe`。
2. 正常启动并登录 LOL，等待助手识别客户端。
3. 到“设置 → 对局自动化”选择“排位”或“大乱斗”辅助预设，再按自己的习惯调整。
4. 进入选人，查看伴随窗，确认符文与装备配置结果。
5. 想查历史战绩或复盘时，打开“战绩查询”。

预设会调整多项开关。自动选禁、自动喊话和云端 AI 等功能请按需单独设置。详细入口、操作步骤和排查方法见 [完整玩家使用指南](docs/玩家使用指南.md)。

## 关于实验性功能

“游戏换肤”是单独、默认关闭的实验性模块，包含英雄、小兵、眼位和视距相关选项。它不等于拥有账号皮肤，游戏更新后可能需要重新适配，第三方换肤存在账号处罚风险。段位边框等项目是否可用，以页面提示为准。

技能冷却计时目前为功能预览，暂不能开启。
