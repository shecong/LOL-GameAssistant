## 功能

### 1. 各个功能模块

> 现在是七个标签页：首页、好友、对局、战绩查询、关于、设置、日志。

**首页**

打开就是自己的东西。头像、名字、等级、升级还差多少经验，下面单双排和灵活组排分成两张卡，段位图标、胜率、胜场负场、当前 LP、历史最高段位都摆着。再往下还有六项细账：定级赛打没打完、晋级赛目前几胜几负、这赛季打了多少场、隐藏分、赛季什么时候结束。

战绩卡会跟着窗口宽度自己调列数，窗口拉宽一行能塞进更多。每张战绩卡右边排着这局 10 个人的头像，我方一个色、敌方一个色，自己是金框。想看谁点谁的头像，直接跳到战绩查询去查他。

**好友**

把客户端的好友列表搬过来了，在线、手机在线、离线分得清楚，顶上会写着"共 N 位好友 · 在线 M 位"和更新时间。双击某个好友就能查他的战绩。

**对局**

进游戏或者刚进选人阶段，这页会自动把当前对局的人拉过来。蓝方红方分开排，卡片跟着宽度自适应，全屏的时候同队还能两两并排。谁是自己队友、谁是对手，都标出来了。

重点说下开黑检测。做法是拿每个人最近 20 场的战绩互相比对，两个人反复排到同一边（同队 2 次以上）就认为是开黑，再用并查集把这些关系串成一个个小组。表头会给出"2+2"这种人数摘要，卡片上标"开黑①"，鼠标放上去能看见这个组都有谁。只看段位是看不出开黑的，这个功能在实际对局里比想象中有用——遇到过对面三黑的情况一眼就能看出来。

每张玩家卡下面还带着他近 10 场的战绩，几胜几负和胜率都算好了。

**战绩查询**

输入 puuid，或者直接写"名称#TAG"，能查任何一个玩家。上面是统计看板：总胜率、平均 KDA、KDA 趋势折线（绿点赢红点输）、常用英雄 Top10，还能按模式筛。下面是战绩列表，赢的绿输的红，一行行写着英雄、模式、日期、KDA、时长，鼠标划过会变色。双击任意一行看这局的详情。

顺手加了收藏和导出：常查的人可以收藏起来；战绩能导成 CSV，英雄、KDA、补刀、伤害、金币、视野、出的装备都在里面，想自己拉去表格里分析也行。

**关于**

软件介绍、GitHub 地址，还有检查更新——会去 GitHub 拉一下最新的 release，有新版本就直接给你跳转过去。

**设置**

自动匹配对局、自动接受对局、自动禁英雄、自动选英雄，四个开关各自独立。禁英雄和选英雄都是多选，选完能看到英雄头像预览。自动禁用有个间隔设置（秒），选英雄不吃这个间隔——抢英雄是另开了一条快速轮询，选人动作一出来就提交，晚一秒可能就没了。

其他还有分辨率、最小化到托盘、对局自动刷新和刷新间隔、对局结束提醒、开机自动启动，以及本地缓存文件在哪。

**日志**

软件出错的信息、LCU 的端口和密钥都在这儿，排查问题用。客户端没开的时候它会每 10 秒探一次，开了自动接上；中途断线也会自己重连，不用手动重启软件。

### 3. 待优化完善地方

> 1. 数据全指望本机客户端，客户端一关就什么都查不到。想过要不要本地攒一份战绩库，或者接个第三方数据源兜底。
> 2. 英雄数据现在是写死在代码里的，一百多条，出个新英雄或者改个译名就得手动加一遍。客户端和 DataDragon 本来就能给这份数据，早晚得换掉。战绩
> 3. 战绩查询页越写越胖了，再往里加东西之前得先拆一拆。
> 4. 对局数据还是每次现拉，缓存做得不够（开黑检测有 5 分钟缓存，其他基本没有）。
> 5. 本来说想把 LOL-GameApi 那个 Web API 工程用起来做共享缓存，到现在还没接上主程序。
> 6. 高分屏和小窗口下手算的那些布局还得再调，偶尔会对不齐。
