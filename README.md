# LOL GameAssistant（英雄联盟游戏助手）

基于 .NET 10 WinForms 的英雄联盟客户端辅助工具。通过 LCU（League Client Update）本地接口读取玩家数据，并支持自动匹配、自动接受、自动禁用/选用英雄等操作。

## 功能

- 首页：卡片式布局（搜索/玩家信息/排位/近期战绩）；排位卡区分单双排（排位赛）与灵活组排，展示段位、胜点、胜率、最高段位及定级赛/晋级赛/场数/隐藏分/赛季结束六项明细；战绩卡自适应多列（窗口越宽每行卡片越多），展示本局 9 名玩家头像（区分我方/敌方，自己高亮）与时长、补刀、伤害、金币
- 对局：开局/切页/阶段变化自动获取；蓝方/红方玩家卡片自适应排列（全屏宽度下同队卡片可两两并列），自动判断并标识“我方/敌方”与每名玩家的“队友/对手”（同队蓝框、异队红框）；开黑检测基于每人最近 20 场战绩统计同队次数（≥3 次判定组队），表头显示“开黑 2+2/3”人数摘要、卡片显示“开黑①”组标及同组成员；支持复制 ID、双击战绩行查看对局详情
- 战绩查询：支持 `puuid`、`名称#TAG` 查询任意玩家，分页（10/20 每页）、统计看板（胜率、平均 KDA、KDA 趋势、常用英雄 Top10、模式筛选）；战绩列表按胜负红/绿配色、圆角卡片逐行区分（英雄、模式、日期、KDA、时长，悬停变色、逐行入场动效），双击查看本局详情
- 自动化：自动匹配对局、自动接受对局、自动禁用/选用英雄（英雄多选 + 头像预览）
- 效率功能：玩家收藏、战绩导出 CSV、对局数据自动刷新、对局结束托盘提醒、开机自启
- 稳定性：日志窗口、全局异常处理、error.log、LCU 断线自动重连

## 构建

```bash
dotnet build LOL-GameAssistant.slnx
```

## 使用前提

- Windows 系统，已安装 .NET 10 SDK
- 本机运行英雄联盟客户端并完成登录
- 程序通过读取客户端 `lockfile` / WMI 命令行自动发现 LCU 端口与令牌，无需管理员权限

## 数据来源

- 玩家/排位/战绩/对局数据：本机 LCU API（`https://127.0.0.1:{port}`，Basic Auth）；排位解析失败时写入 `ranked_debug.log` 便于诊断
- 游戏版本：DataDragon CDN（`ddragon.leagueoflegends.com`）

## 本地文件

- `settings.json`：应用设置（自动保存）
- `favorites.json`：收藏玩家
- `error.log`：异常日志

## 说明

本项目为个人学习/辅助工具，仅在本机与 LOL 客户端交互，不修改游戏文件、不注入游戏进程。
