# LOL 对局小助手

这是一个围绕英雄联盟客户端信息制作的小工具。它的初衷很简单：把排队、进入对局和查看战绩时常用的信息放在一起，少一些来回切换和手动查询。

项目还在持续完善中。目前的功能或许不算复杂，但希望能让查看对局信息这件事更顺手一些。

程序需要管理员权限运行。双击启动时 Windows 会请求管理员授权；取消授权则不会启动主窗口。

## 功能一览

新增首页快捷入口、辅助预设、方案对比解释、一分钟复盘、个人练习目标、主练版本关注以及常用队友和招募筛选。入口、统计边界及验证说明见[三阶段体验升级](COMPANION_EXPERIENCE.md)。

新增开黑大厅、英雄池档案与个人复盘中心，战绩查询中可直接切换两个成长页签。现有接口诊断、选人快照、回放、备份、奖励、组合方案、数据来源、赛后自动化与 OCR 校正也已接入优化。入口与统计口径见[开黑与成长使用说明](COMPANION_FEATURES.md)。

### 游戏换肤（实验性）

在主菜单“游戏换肤”中打开“启用独立核心”开关，进入对局后读取当前英雄，搜索并选择皮肤/形态，选择后自动应用。可恢复基础皮肤；关闭开关会停止刷新和新请求，不会强制卸载游戏内模块或自动还原皮肤。开关状态保存到本地，默认关闭；启动助手本身不会连接换肤核心。

成功应用的皮肤与形态会按英雄保存到本地。核心开启时，下次进入对局会自动应用该英雄上次选择的皮肤，无需打开换肤页面；重启助手后仍保留。手动选择和快捷键切换都会更新记忆。“恢复基础皮肤”或成功“恢复并停用”会清除当前英雄的记忆。已失效的目录条目不会自动应用，请重新选择。

对局中按 `Home`（可在换肤快捷键设置中修改）打开统一换肤弹窗，可切换“英雄皮肤 / 眼位皮肤 / 小兵皮肤”。点击条目立即应用，离开换肤页面也可使用；目录较长时可翻页。小兵与眼位复用同一套本局对象同步，更换其中一类会保留另一类已应用的选择；眼位只作用于自己的眼位。对象分类的“恢复小兵与眼位”会恢复两类对象并停止同步；英雄分类仍单独恢复英雄。切出游戏、关闭核心或结束对局后隐藏弹窗。

页面下方可启用“游戏内快捷键”，默认上一款 `Ctrl+Alt+←`、下一款 `Ctrl+Alt+→`。点击输入框按组合键录制，再保存；与现有功能冲突的组合不会启用。快捷键仅在游戏前台、对局进行中且核心开启时生效，切换助手页面后仍可使用。上一款/下一款按完整原版目录循环（包含形态）并立即应用；切换成功后，游戏上方显示皮肤名称和形态，3 秒后自动隐藏，切出游戏也会隐藏。对局变化后需重新读取和选择。连续按键会限流，执行中的请求不会叠加。

独立核心随运行包的 `Tools/SkinCore` 发布，不依赖 Python 或原版小助手。游戏版本不匹配时停止调用；“状态已核验”不代表画面、技能及稳定性测试全部通过，也不代表免封号。第三方换肤有账号处罚风险。

源码在 `native/LeagueSkinCore`，重建配套文件执行 `powershell -File tools/build-skin-core.ps1 -Rebuild -Test`。集成说明见 [换肤核心集成评估](docs/换肤核心集成评估.md)。

按功能查看完整使用步骤：[用户说明手册](docs/用户说明手册.md)。

应用包含首页、好友、对局、战绩查询、关于、设置、日志、智能建议和运行诊断页面。

智能建议采用本机事实驱动的行动计划：低血状态即时提醒，AI 按选人、对线、技能、发育、装备、资源、团战和复活等场景给出步骤、条件、依据、收益与备选方案。空泛或引用缺失事实的输出被拦截，失效计划自动撤下。完整流程、数据边界、预算与验证见 [AI 时间线设计与实现](AI建议优化说明.md)。

“关于”前新增 **lol休息室**：连接统一服务器后可公共聊天、查看助手用户的 LOL 状态，并自动播报已核对的常见模式胜局。服务端部署和地址配置见 [休息室说明](LOL-GameApi/LOUNGE.md)。

休息室默认显示最新 40 条，向上按批次加载历史；支持分类筛选、阅读位置保持和新消息提示。完整历史分页需同步更新 LOL-GameApi 至协议 v4，见[消息分页与新版布局说明](LOUNGE.md)。

首页和对局页获取玩家资料、段位、战绩列表或单局详情时，接口返回空数据会回退到最近 30 天内保存的本地缓存；成功响应更新缓存，空响应不覆盖已有数据。缓存按玩家和分页区间隔离，可在“设置 → 本地缓存”清理。对局阵容仅在当前流程阶段内保留，阶段切换或对局结束后清空。

战绩查询和对局页支持“回到顶部”。战绩详情补齐时保留当前阅读位置，滚动范围随内容更新；对局卡片内的记录滚到边界后不会继续带动外层队伍列表，记录无需滚动时则直接滚动队伍列表。

滚动布局回归测试需在 Windows 上运行：`dotnet test LOL-GameAssistant.UiTests/LOL-GameAssistant.UiTests.csproj`。

## 选人与海克斯大乱斗

- **个人符文方案**：选人时先设置好符文和召唤师技能，在“智能建议 → 我的符文方案”中捕获。方案按英雄、模式和峡谷分路保存，可修改名称、优先级和自动应用开关，也可手动应用或删除。选人自动应用在“设置 → AI 与推荐”中开启；没有匹配的个人方案时，使用对应模式的 OP.GG 推荐。写入仅替换助手创建的符文页。
- **海克斯大乱斗出装与增幅**：该模式使用独立的出装、召唤师技能和英雄增幅统计。模式没有常规符文页，助手在应用出装时保留客户端当前符文。数据分别来自 [aramgg](https://aramgg.com/en/augments)、[ARAMKit](https://aramkit.com/en-US/augments/vulnerability) 和 [CommunityDragon](https://raw.communitydragon.org/latest/cdragon/arena/en_us.json)。
- **局内增幅侧边栏与 OCR**：在“设置 → AI 与推荐”开启后，海克斯大乱斗对局中显示专属侧边栏。三张增幅卡片出现时点击“扫描当前增幅”，程序截取本机游戏窗口中央区域，使用 SimdPaddleOCR 的内嵌 PP-OCRv6 Small 模型在本机识别，并按当前英雄样本胜率排序。OCR 核心和模型随单文件主程序发布，不需要外部 Tesseract DLL 或语言数据目录。截图仅在内存中处理。侧边栏仅在游戏前台且处于窗口或无边框模式时显示；独占全屏自动隐藏并停止自动截图识别。不加载游戏覆盖层模块。
  推荐增幅按白银、黄金、棱彩三个类型切换，每类独立按英雄样本胜率排序；扫描结果同步标注类型。类型信息随离线名称表发布，不增加分类切换时的网络请求。
- **选人伴随窗**：在“设置 → AI 与推荐”开启，选人时显示队友段位和近期战绩。紧凑窗口贴在 LeagueClientUx 侧边，随客户端移动、缩放和最小化。点击“一键选择符文装备”可按当前英雄、位置和模式打开方案选择窗口；海克斯大乱斗选人时还会列出当前备战席全部可交换英雄，点击英雄即可快速交换。
- **大乱斗备战席交换**：在“设置 → 对局自动化”开启，按备战席英雄列表的选取顺序设定优先级。仅当备战席有比当前英雄更高优先级的英雄时自动交换。
  伴随窗中的可交换英雄通过选人事件即时更新，进入选人阶段立即读取，并以约 500ms 的独立轮询补漏；模式查询和队友战绩加载不会阻塞英雄按钮显示。
- **中英文界面**：在“设置 → 外观与窗口”选择语言后立即切换，并保存到本地设置；切回中文也无需重启。

### 首页

可以快速查看自己的段位和近期战绩，也支持搜索其他玩家的基础信息。

### 对局

进入对局后，可查看当前对局中所有玩家的战绩信息，并展示各自最近九场对局记录，方便在开局前有一个大致了解。

游戏中按住键盘左上角的 **· / ` 键**可查看独立的双方对局信息面板，松开或切出游戏后隐藏。可在“设置 → AI 与推荐 → 局内对局信息面板”关闭功能或录入自定义单键、Ctrl / Alt / Shift 组合键，修改后自动保存并生效。游戏中使用面板快捷键，客户端和桌面使用原有的按住置顶键。

面板展示英雄、玩家标识、段位、赛季场次和胜率、近十场同模式胜负与 KDA，以及本局 KDA、补刀和视野得分。英雄胜率仅统计最近100场返回战绩中的同模式英雄样本，样本数和胜负场数同时显示，胜率保留一位小数；灵活组排展示灵活段位，其余展示单双排段位。实时接口没有插眼数量，视野得分不作为插眼次数。未获取的数据显示为“—”。请使用游戏窗口或无边框模式；独占全屏时自动隐藏局内浮窗。

局内对局信息面板的每名玩家下方还展示本局**天赋（基石、主系、副系）**和**两个召唤师技能**的图标、名称。数据来自本机实时接口，不会拿上一场的配置代替本局配置；海克斯大乱斗没有常规符文时显示说明，接口未提供的数据保留为“—”。

### 战绩查询

用于展示个人更详细的战绩内容。每场记录支持“下载回放”和“观看回放”，无需手动输入对局 ID；先下载完整回放，再通过已连接的英雄联盟客户端观看。回放是否可用取决于客户端支持、录像保留期限和游戏版本。

### 关于

介绍项目的背景、功能方向，以及项目仓库地址。

启动后会在后台检查 GitHub 最新正式发布版本。有新版本时可选择前往 GitHub 下载，或加入 QQ 群 **1067459719** 获取，也可点击“稍后再说”继续使用当前版本。自动检查失败不打断启动；可在“关于 → 软件更新”手动检查。

包含原生 `Updater.exe` 的运行包还支持“下载更新 → 重启并安装”：后台下载并校验完整包，用户选择安装时间，失败时恢复旧文件。开发构建、更新配置、GitHub Release 发布及中断恢复步骤见 [自动更新操作说明](UPDATE.md)。

### 设置

可以按自己的使用习惯调整以下选项：

* 自动匹配对局
* 自动接受对局
* 自动禁用英雄
* 自动选择英雄
* 定时检查间隔

自动禁用和自动选择英雄通过本机客户端选人接口执行，可在列表中设定优先英雄。

### 日志

记录软件运行时的异常和客户端连接诊断信息，便于定位问题。日志可能含有本地敏感信息，如需分享给他人排查，请先确认内容已做必要处理。
