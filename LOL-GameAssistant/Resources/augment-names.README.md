# 强化中文名数据

`augment-names.json` 在 2026-09-24 生成，仅保存强化 ID、中文名和可用的图标地址。程序把它嵌入单文件发布包，战绩页离线时仍能将海克斯大乱斗的强化 ID 显示为中文名。

- 海克斯大乱斗：<https://hextech.dtodo.cn/data/aram-mayhem-augments.zh_cn.json> 的 `id` / `displayName`。
- 斗魂竞技场：<https://raw.communitydragon.org/latest/cdragon/arena/zh_cn.json> 的 `id` / `name` / `iconSmall`。

新赛季出现未知 ID 时，更新这个映射文件即可；界面会对未知 ID 显示编号。

2026-10-31 已与海克斯大乱斗数据源核对并同步：源表共 282 条，比内置旧表新增 35 条（ID 3004–3163 中的部分条目），无已有名称变更，并补齐 31 个已有条目缺失的稀有度。合并后名称表共 507 条，保留竞技场及历史 ID；新增条目同时保存真实稀有度，供 OCR 名称匹配和推荐分组使用。源表未提供可直接使用的图标 URL 或英文显示名，新增条目不猜测这些字段。

在仓库根目录运行 `node tools/sync-mayhem-augments.mjs --check` 检查上游差异（有差异时退出码为 1），去掉 `--check` 同步名称、稀有度及说明。更新前会校验全部条目，不删除历史 ID。此脚本用于更新发布包的内置兜底资源。

程序运行时也会自动更新海克斯大乱斗对照表：启动后后台检查，成功后每 6 小时复查，失败后 5 分钟重试；扫描卡片和读取增幅推荐前也会复用同一检查任务及检查间隔。上游支持 ETag 时发送 `If-None-Match`，收到 304 则沿用本地版本；否则下载并以 SHA-256 内容摘要判断版本变化。无需匹配游戏补丁号，因为上游未提供独立的补丁版本字段。

校验完整的 ID、名称、稀有度及说明后，更新立即用于后续扫描、校正列表、推荐与战绩查询。历史内置 ID、英文名和已有图标地址保留。缓存原子写入 `%LOCALAPPDATA%/LOL-GameAssistant/mayhem-augments-cache.json`，下次启动先验证摘要并读取缓存。网络失败、内容不合法或缓存损坏时继续使用有效缓存或内置表；磁盘不可写时仍可使用本次下载的内存版本。最多接受 4 MiB、至少 200 条的上游表，防止错误响应覆盖有效数据。更新状态可在运行诊断的“增幅对照表”查看。安装支持此功能的新程序后，后续对照表更新无需重新编译或重启。

`augment-descriptions.json` 在 2026-10-06 从上述海克斯大乱斗数据源的 `description` 字段生成，保存 247 条中文作用说明，并嵌入发布包。优先使用说明字段，避免将需要局内动态参数的 tooltip 当作确定数值显示。详情窗口将游戏富文本标签转换为普通文本；新版本更新名称时也应同步更新说明文件。

2026-10-31 已同步新增的 35 条说明，目前共 282 条。实际装备名称、说明及图标另从当前 LCU 客户端的 `/lol-game-data/assets/v1/items.json` 读取，不使用此增幅名称表。
