# 文件皮肤资源

支持两种布局：

- `manifest.json` + `skins.plskin`：按需读取和解密单个 fantome，并校验索引中的大小和 SHA256。
- `manifest.json` + `skinlib/`：优先读取本地 fantome 库，不打开加密包。库支持索引 `fileName` 的相对路径，以及文档所述 `英雄/皮肤/显示名称.fantome` 布局。

资源缺失时隐藏文件引擎入口。曾选择文件模式但资源后来缺失时保留入口，便于切回内存模式，且不会自动启动内存换肤。

使用：主导航分为“游戏内换肤”和“游戏外换肤”两个独立标签。游戏外页面采用英雄侧栏、卡片画廊、收藏与命名预设、底部选择栏；支持中英文搜索、跨英雄检索及炫彩/形态筛选。每页最多创建 16 张皮肤卡片，图片通过独立服务按需加载并缓存，不依赖游戏内目录或预览状态。

先退出对局，在“游戏外换肤”选择 Game 目录，点击卡片加入皮肤，然后点击底部应用按钮。等待准备完成再进入游戏。同英雄再次选择会替换已有选择。浏览不会切换引擎；应用时通过独立协调器等待内存请求结束、切换引擎归属，再启动文件层。回到“游戏内换肤”打开功能时才会切回内存层。停止操作只停止本助手拥有的进程，已加载的游戏画面需要退出对局后才能完全释放。

收藏和命名预设存放在用户目录 `LOL-GameAssistant/Cslol/browser.json`，与游戏内的皮肤记忆分开保存。页面、选择模型、偏好存储、图片服务、进程调度各自独立。
